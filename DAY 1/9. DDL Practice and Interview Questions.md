# Day 1: DDL Practice and Interview Questions

Now that you have learned the syntax for Data Definition Language (DDL) and constraints, let's practice using them step-by-step and review common questions asked in tech interviews.

---

## 1. DDL Step-by-Step Practice Scenario

Open your MySQL CLI client and run these 13 steps in order to practice structural changes:

### Step 1: Create a Database
```sql
CREATE DATABASE college;
```

### Step 2: Select the Database
```sql
USE college;
```

### Step 3: Create the `student` Table
```sql
CREATE TABLE student (
    id INT,
    name VARCHAR(50),
    age SMALLINT,
    marks SMALLINT
);
```

### Step 4: Verify the Table Exists
```sql
SHOW TABLES;
```

### Step 5: Add a new `city` Column
```sql
ALTER TABLE student
ADD city VARCHAR(30);
```

### Step 6: Modify the Datatype of `city`
```sql
ALTER TABLE student
MODIFY city CHAR(50);
```

### Step 7: Rename the `city` Column
```sql
ALTER TABLE student
CHANGE city student_city CHAR(50);
```

### Step 8: Rename the Table to `students`
```sql
ALTER TABLE student
RENAME TO students;
```

### Step 9: Drop the `student_city` Column
```sql
ALTER TABLE students
DROP COLUMN student_city;
```

### Step 10: Rename the Table Back to `student`
```sql
RENAME TABLE students TO student;
```

### Step 11: Remove All Records (Keeping Structure)
```sql
TRUNCATE TABLE student;
```

### Step 12: Delete the Table Permanently
```sql
DROP TABLE student;
```

### Step 13: Delete the Database Permanently
```sql
DROP DATABASE college;
```

## 2. Top DDL Interview Questions

Here are the most frequently asked questions during technical interviews regarding SQL DDL:

### Q1: What is DDL and what does it do?
*   **Answer:** **DDL** stands for **Data Definition Language**. It is a sublanguage of SQL used to define, alter, and delete database structures (schemas, databases, tables, columns, indexes, triggers). It focuses on the database *blueprint*, not the data itself.

### Q2: List the DDL commands and their purposes.
*   **Answer:**
    *   `CREATE`: Creates databases and table structures.
    *   `ALTER`: Modifies an existing table's columns, datatypes, or names.
    *   `DROP`: Deletes tables or databases permanently.
    *   `RENAME`: Renames a table.
    *   `TRUNCATE`: Removes all records inside a table instantly while preserving the empty structure.

### Q3: What is the difference between DROP and TRUNCATE?
*   **Answer:**
    *   **`DROP`**: Deletes the entire table structure, columns, constraints, and data permanently from the database. The table ceases to exist.
    *   **`TRUNCATE`**: Deletes all data rows inside the table, but keeps the columns and table definition intact. It's a quick way to empty a table for fresh entries.

### Q4: What is the difference between ALTER TABLE ... RENAME TO and RENAME TABLE?
*   **Answer:**
    *   Both commands achieve the exact same result (renaming a table).
    *   `ALTER TABLE ... RENAME TO` is part of the standard `ALTER` command syntax used for general modifications.
    *   `RENAME TABLE` is a specific standalone utility command in MySQL that can also rename multiple tables in a single line (e.g., `RENAME TABLE old1 TO new1, old2 TO new2;`).

### Q5: Can you roll back a TRUNCATE command?
*   **Answer:** In MySQL, DDL commands (like `TRUNCATE`, `DROP`, `ALTER`, `CREATE`) cause an **implicit commit**. This means they are saved immediately and cannot be rolled back using a transaction `ROLLBACK` command.
