# Day 1: Creating Databases and Tables

Now we will get our hands dirty and learn how to create a database, design a table, and define constraints. 

---

## 1. Creating and Managing Databases

First, we need to create a container (database) to hold our tables.

### Create a Database
To create a new database named `school_db`:
```sql
CREATE DATABASE school_db;
```

### Show All Databases
To verify the database was created:
```sql
SHOW DATABASES;
```

### Use/Select a Database
Before creating tables, you must tell MySQL which database you want to work inside:
```sql
USE school_db;
```

### Delete (Drop) a Database
> [!CAUTION]
> Dropping a database deletes the database and **all tables and data** inside it permanently!
```sql
DROP DATABASE school_db;
```

## 2. Table Creation and Constraints

Tables are defined using the `CREATE TABLE` command. 

When creating a table, we specify the columns, their data types, and **Constraints** (rules that enforce data integrity).

### Common SQL Constraints:

To remember the main constraints easily, use the memory phrase: **P.N.D.U.F.** (*"Please Never Drop Us, Friends"*)

*   **P** - **`PRIMARY KEY`**: Uniquely identifies each row. Must be unique and cannot be empty (NOT NULL).
*   **N** - **`NOT NULL`**: Prevents a column from having an empty/blank (`NULL`) value.
*   **D** - **`DEFAULT`**: Automatically inserts a default value if no value is provided.
*   **U** - **`UNIQUE`**: Guarantees that all values in a column are different (no duplicates).
*   **F** - **`FOREIGN KEY`**: Links one table to another to ensure data relationships remain consistent.

*Optional Helper:*
*   **`AUTO_INCREMENT`**: Automatically bumps up the number by 1 for every new record (typically used with Primary Keys).

### Example: Creating a `students` Table
Let's create a table to store student records:

```sql
CREATE TABLE students (
    student_id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    enrollment_date DATE NOT NULL,
    status VARCHAR(20) DEFAULT 'Active'
);
```

## 3. Inspecting the Table Structure

After creating a table, you can inspect its schema using the following commands:

### Show Tables
Lists all tables in the current active database:
```sql
SHOW TABLES;
```

### Describe Table
Shows the details of columns, types, nullability, keys, and default values:
```sql
DESCRIBE students;
```
*(Or you can use `DESC students;` or `EXPLAIN students;`)*

### Show Create Table
Shows the exact SQL statement used to generate the table:
```sql
SHOW CREATE TABLE students;
```

---

## 4. Deleting a Table

If you need to delete a table completely:
```sql
DROP TABLE students;
```

If you want to clear all data inside a table but keep the structure/columns:
```sql
TRUNCATE TABLE students;
```
