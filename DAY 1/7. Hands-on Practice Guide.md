# Day 1: Hands-on Practice Guide

This guide walks you through a complete, step-by-step practical case study: **Building a Library Management System**. 

We will apply all the Day 1 concepts—creating a database, defining a table with constraints, and executing CRUD queries.

---

## The Scenario
Imagine you are building a database for a local bookstore or library. You need to keep track of books, their authors, publication years, prices, and whether they are currently in stock.

---

## Step 1: Database Setup

First, open your MySQL Command Line or GUI and run these commands to set up a clean database:

```sql
-- 1. Create a new database
CREATE DATABASE library_db;

-- 2. Select the database for use
USE library_db;
```

---

## Step 2: Designing and Creating the Table

We will design a `books` table with the following requirements:
*   `book_id`: Unique ID for each book (auto-generated).
*   `title`: The title of the book (cannot be blank).
*   `author`: The author's name (cannot be blank).
*   `isbn`: International Standard Book Number (must be unique for every book).
*   `price`: Book price (exact decimal, e.g., $19.99).
*   `stock_count`: Number of copies available (defaults to 0 if not specified).
*   `published_date`: Date the book was published.

### SQL Query:
```sql
CREATE TABLE books (
    book_id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(150) NOT NULL,
    author VARCHAR(100) NOT NULL,
    isbn VARCHAR(20) UNIQUE NOT NULL,
    price DECIMAL(6, 2) NOT NULL,
    stock_count INT DEFAULT 0,
    published_date DATE
);
```

### Verify the Structure:
Run the describe command to make sure the constraints are applied properly:
```sql
DESCRIBE books;
```

---

## Step 3: Populate Data (CREATE / INSERT)

Let's insert some books into our table. We will cover different scenarios:

### Scenario A: Insert single book (providing all columns)
```sql
INSERT INTO books (title, author, isbn, price, stock_count, published_date)
VALUES ('The Great Gatsby', 'F. Scott Fitzgerald', '9780743273565', 15.99, 12, '1925-04-10');
```

### Scenario B: Insert multiple books (bulk insert)
```sql
INSERT INTO books (title, author, isbn, price, stock_count, published_date)
VALUES 
('To Kill a Mockingbird', 'Harper Lee', '9780446310789', 12.50, 8, '1960-07-11'),
('1984', 'George Orwell', '9780451524935', 9.99, 15, '1949-06-08'),
('The Hobbit', 'J.R.R. Tolkien', '9780547928227', 22.00, 5, '1937-09-21');
```

### Scenario C: Insert using default values (omitting `stock_count`)
Because `stock_count` has a `DEFAULT 0` constraint, we can omit it, and MySQL will auto-fill it:
```sql
INSERT INTO books (title, author, isbn, price, published_date)
VALUES ('New Release Book', 'Unknown Author', '9781111111111', 29.99, '2026-01-01');
```

---

## Step 4: Querying Data (READ / SELECT)

Let's query our books using different filters.

### Query 1: View all records
```sql
SELECT * FROM books;
```

### Query 2: View only titles and prices
```sql
SELECT title, price FROM books;
```

### Query 3: Find cheap books (under $15.00)
```sql
SELECT title, author, price FROM books
WHERE price < 15.00;
```

### Query 4: Find books with high stock (10 or more copies)
```sql
SELECT title, stock_count FROM books
WHERE stock_count >= 10;
```

---

## Step 5: Updating Records (UPDATE)

### Scenario A: A customer buys a book (reducing stock)
Let's reduce the stock of '1984' (which has `book_id = 3`) by 1:
```sql
UPDATE books
SET stock_count = 14
WHERE book_id = 3;
```

### Scenario B: Price adjustment for a book
Let's update the price of 'The Hobbit' (which has `book_id = 4`):
```sql
UPDATE books
SET price = 19.99
WHERE book_id = 4;
```

---

## Step 6: Removing Records (DELETE)

### Scenario: Removing a damaged or obsolete book
Let's delete the 'New Release Book' (which has `book_id = 5`):
```sql
DELETE FROM books
WHERE book_id = 5;
```
