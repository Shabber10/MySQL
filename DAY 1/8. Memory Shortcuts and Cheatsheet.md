# Day 1: Memory Shortcuts and Cheatsheet

Studying database commands can feel like alphabet soup. To help you master these concepts instantly, we have compiled the absolute best **Memory Mnemonics, Shortcuts, and Visual Cheatsheets**.

These tricks are designed to be intuitive for everyone—from absolute beginners to advanced learners!

## 🐱 1. SQL Sublanguages: The "DR. CAT" Rule

Whenever you are working with SQL, the commands are grouped by *what they do*. Remember them using these easy-to-visualize keywords:

```
  DDL   ===>   DR. CAT (Drop, Rename, Create, Alter, Truncate)
  DML   ===>   U-I-D   (Update, Insert, Delete)
  DQL   ===>   S       (Select)
  TCL   ===>   C-R-S   (Commit, Rollback, Savepoint)
  DCL   ===>   G-R     (Grant, Revoke)
```

### Detailed Breakdown:
*   **DDL (Data Definition Language) ➡️ *DR. CAT***
    *   **D**rop *(Deletes structure)*
    *   **R**ename *(Changes name)*
    *   **C**reate *(Makes new structure)*
    *   **A**lter *(Modifies structure)*
    *   **T**runcate *(Wipes data, keeps structure)*
*   **DML (Data Manipulation Language) ➡️ *U-I-D* (think: "User ID")**
    *   **U**pdate *(Modifies entries)*
    *   **I**nsert *(Adds entries)*
    *   **D**elete *(Removes entries)*
*   **DQL (Data Query Language) ➡️ *S* (think: "Search")**
    *   **S**elect *(Fetches data)*
*   **TCL (Transaction Control Language) ➡️ *C-R-S* (think: "Cars Run Safely")**
    *   **C**ommit *(Saves work)*
    *   **R**ollback *(Undoes work)*
    *   **S**avepoint *(Temporary checkpoint)*
*   **DCL (Data Control Language) ➡️ *G-R* (think: "Guard Room" or "Grant Privileges")**
    *   **G**rant *(Gives access)*
    *   **R**evoke *(Takes back access)*

## 🔒 2. Table Constraints: "P.N.D.U.F."

Constraints are guards that keep your data accurate. Remember them with the phrase: 
> **"Please Never Drop Us, Friends"**

*   **P** ➡️ **`PRIMARY KEY`** (The unique ID, e.g. passport number. Can never be blank, must be unique).
*   **N** ➡️ **`NOT NULL`** (Required field, e.g., you *must* enter your email to sign up).
*   **D** ➡️ **`DEFAULT`** (The fallback option, e.g., if you don't select a status, it defaults to 'Active').
*   **U** ➡️ **`UNIQUE`** (No duplicates allowed, e.g., usernames).
*   **F** ➡️ **`FOREIGN KEY`** (A bridge connecting two tables together).

## 🔄 3. CRUD Operations to SQL Command Mapping

**CRUD** is a software engineering term for basic operations. Here is how it maps directly to SQL commands:

| CRUD Term | Meaning | SQL Equivalent | Analogy |
| :--- | :--- | :--- | :--- |
| **C**reate | Add brand new data | **`INSERT`** | Writing a new contact in your phone address book |
| **R**ead | View or find data | **`SELECT`** | Opening the address book to search for a name |
| **U**pdate | Edit existing data | **`UPDATE`** | Changing a friend's phone number in your contact list |
| **D**elete | Remove data | **`DELETE`** | Deleting a contact you no longer talk to |

## 🚀 4. Sneak Peek: Order of SQL Query Execution

When writing a search query in SQL (Day 2+ concept), the commands *must* be written in a specific order, or SQL will crash. Use this mnemonic to remember the sequence:

> 🦖 **"Some Fine Wolves Growl Heavily Outdoors Late"**

1.  **S**ome ➡️ **`SELECT`** *(Which columns to see)*
2.  **F**ine ➡️ **`FROM`** *(Which table to search)*
3.  **W**olves ➡️ **`WHERE`** *(Filter conditions)*
4.  **G**rowl ➡️ **`GROUP BY`** *(Aggregate data into groups)*
5.  **H**eavily ➡️ **`HAVING`** *(Filter conditions on grouped data)*
6.  **O**utdoors ➡️ **`ORDER BY`** *(Sorting results ascending or descending)*
7.  **L**ate ➡️ **`LIMIT`** *(How many rows to return)*

## 💡 Pro Tips for Command Line Beginners

*   **"Missing Semicolon (`;`)" Trait:** If you hit enter and see a `->` prompt, MySQL is waiting for you to end your command with a `;`. Simply type `;` and hit enter.
*   **Directional Arrow Keys:** Press the **Up Arrow Key** on your keyboard to instantly see and reuse the last query you typed. You don't need to retype long queries!
*   **Case Insensitivity:** SQL doesn't care if you write `select` or `SELECT`. However, writing keywords in **UPPERCASE** and table/column names in **lowercase** makes your queries look neat and professional.
