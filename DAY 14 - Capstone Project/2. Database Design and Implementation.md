## 📐 1. ER Diagram & Schema Architecture

The database follows **3rd Normal Form (3NF)** rules across 6 core tables:

```
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│  Categories  │───1:N──>│   Products   │───1:N──>│  OrderItems  │
└──────────────┘         └──────────────┘         └──────┬───────┘
                                                         │
┌──────────────┐                                         │ N:1
│  Customers   │──────────────────1:N───────────────────>│   Orders     │
└──────────────┘                                          └──────────────┘
```

## 🛠️ 2. Core Implementation Components

### A. Schema Definition (3NF)
*   **`Customers`**: Stores customer demographic information.
*   **`Categories`**: Product category lookup table.
*   **`Products`**: Product inventory with stock and price.
*   **`Orders`**: Order header records (Customer ID, Date, Status, Total Amount).
*   **`OrderItems`**: Order line items linking products and orders.
*   **`PriceAudit`**: Automated audit log table.

### B. Business Logic Stored Procedure (`PlaceOrder`)
Executes an **ACID transaction** to deduct product stock and record the order atomically:

```sql
DELIMITER //
CREATE PROCEDURE PlaceOrder(
    IN p_customer_id INT,
    IN p_product_id INT,
    IN p_quantity INT
)
BEGIN
    DECLARE v_price DECIMAL(10,2);
    DECLARE v_stock INT;

    START TRANSACTION;

    -- Check product stock & price
    SELECT price, stock_quantity INTO v_price, v_stock 
    FROM Products WHERE product_id = p_product_id;

    IF v_stock >= p_quantity THEN
        -- Deduct inventory
        UPDATE Products SET stock_quantity = stock_quantity - p_quantity WHERE product_id = p_product_id;

        -- Create order header
        INSERT INTO Orders (customer_id, order_date, total_amount, status)
        VALUES (p_customer_id, CURDATE(), v_price * p_quantity, 'COMPLETED');

        COMMIT;
        SELECT 'Order Placed Successfully!' AS status;
    ELSE
        ROLLBACK;
        SELECT 'Insufficient Stock! Transaction Aborted.' AS status;
    END IF;
END //
DELIMITER ;
```

### C. Analytical View (`vw_SalesSummary`)
Aggregates sales performance by product category:

```sql
CREATE VIEW vw_SalesSummary AS
SELECT 
    c.category_name,
    COUNT(DISTINCT o.order_id) AS total_orders,
    SUM(o.total_amount) AS total_revenue
FROM Categories c
JOIN Products p ON c.category_id = p.category_id
JOIN Orders o ON p.product_id = o.product_id
GROUP BY c.category_name;
```
