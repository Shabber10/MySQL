## 📋 Verification Checklist

- [x] **Schema Integrity (3NF):** All tables are normalized up to 3NF without partial or transitive dependencies.
- [x] **Primary & Foreign Keys:** Primary keys defined on all tables with explicit foreign key cascading constraints.
- [x] **Data Types & Nullability:** Appropriate data types selected (`DECIMAL` for money, `DATETIME` for timestamps, `VARCHAR` for strings).
- [x] **ACID Transactions:** Order processing encapsulated inside `START TRANSACTION ... COMMIT / ROLLBACK` blocks.
- [x] **Triggers:** Audit triggers active on sensitive price updates.
- [x] **Indexes:** Key columns indexed to prevent full table scans.
- [x] **Analytical Views:** Views created to simplify reporting queries.
