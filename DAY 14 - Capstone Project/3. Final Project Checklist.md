## 🛠️ Step-by-Step Test Commands

Refer to `project_schema.sql` for the complete executable script.

```sql
-- Step 1: Execute Order Placement Procedure for Customer 1 (Rahul) ordering 2 Laptops (Product 101):
CALL PlaceOrder(1, 101, 2, @new_order_id, @status_msg);

-- Step 2: Check returned order ID and status message:
SELECT @new_order_id AS created_order_id, @status_msg AS execution_result;

-- Step 3: Verify Inventory Stock Deducted (Laptop stock should drop from 15 to 13):
SELECT product_id, product_name, stock_quantity FROM PRODUCTS WHERE product_id = 101;

-- Step 4: Verify Audit Log entry created by trigger:
SELECT * FROM AUDIT_LOG;

-- Step 5: Query Customer Revenue Ranking View:
SELECT * FROM v_customer_revenue_ranking;

-- Step 6: Test EXPLAIN Query Execution Plan on Orders:
EXPLAIN SELECT * FROM ORDERS WHERE user_id = 1;
```
