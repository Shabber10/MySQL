# Day 14: Chapter 1 — Capstone Project Overview

Welcome to the **Capstone Project**! This project serves as the culmination of your 14-day MySQL journey. You will build a production-grade database for an e-commerce platform called **ShopSphere**.

This project tests and integrates every concept learned throughout the course:
*   **Day 01 - 02:** Data Modeling, DDL, DML, WHERE Filtering, Operators.
*   **Day 03 - 05:** Aggregations, Math/String/Date Functions, Joins, Subqueries, CTEs.
*   **Day 06 - 07:** 3NF Database Normalization, Primary/Foreign Key Constraints.
*   **Day 08:** ACID Transactions (`START TRANSACTION`, `COMMIT`, `ROLLBACK`).
*   **Day 09:** Indexes and Analytical Views.
*   **Day 10:** Stored Procedures and Stored Functions.
*   **Day 11:** Triggers and Audit Automation.
*   **Day 12 - 13:** Security Access Control and Query Tuning.

---

## 🏬 ShopSphere Business Requirements

ShopSphere needs a robust, scalable backend database to handle online ordering, customer management, inventory control, and financial reporting.

### Core System Requirements:
1. **User Management:** Track customer profiles, registration dates, emails, and role-based permissions.
2. **Catalog & Inventory:** Manage product categories, stock quantities, and price histories.
3. **Order Processing:** Handle shopping carts, order placements, line item details, and status updates within **ACID transactions**.
4. **Audit Trail:** Automatically log every price or inventory change into an audit log using **Triggers**.
5. **Business Intelligence:** Provide executive reporting dashboards using **Views** and **Stored Procedures**.
