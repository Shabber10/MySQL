# Day 03: Chapter 4 — Built-in Math, String, and Advanced Functions

In MySQL, **scalar functions** are built-in functions that take one or more inputs and return a **single** value as output. They are incredibly useful in `SELECT` lists, `WHERE` clauses, and `ORDER BY` statements.

---

## 🔢 1. Math and Numeric Functions

Here are the most commonly used mathematical scalar functions in SQL:

### A. ABS(x)
Returns the absolute (positive) value of a number.
*   **Real-time Use:** Calculating differences, financial balances, profit/loss variances.
```sql
SELECT ABS(-500); -- Output: 500
```

### B. DIV
Performs integer division, ignoring the remainder (floor division).
*   **Real-time Use:** Calculating group package counts, item packing.
```sql
SELECT 10 DIV 3; -- Output: 3
```

### C. MOD(a, b)
Returns the remainder of a division (modulo).
*   **Real-time Use:** Checking for even/odd IDs, round-robin cycles.
```sql
SELECT MOD(10, 3); -- Output: 1
```

### D. GREATEST(x1, x2, ...) & LEAST(x1, x2, ...)
Finds the largest or smallest value in a given list of columns or values.
*   **Real-time Use:** Finding max/min values across multiple columns in the same row.
```sql
SELECT GREATEST(10, 20, 30); -- Output: 30
SELECT LEAST(10, 20, 30);    -- Output: 10
```

### E. ROUND(x, d)
Rounds a number `x` to `d` decimal places. If `d` is omitted, it rounds to the nearest integer.
*   **Real-time Use:** Formatting currency, rounding grades.
```sql
SELECT ROUND(12.3456, 2); -- Output: 12.35
SELECT ROUND(4.6);        -- Output: 5
```

### F. TRUNCATE(x, d)
Chops off the decimal part after `d` decimal places **without rounding**.
*   **Real-time Use:** Financial systems where rounding up is not permitted.
```sql
SELECT TRUNCATE(12.3456, 2); -- Output: 12.34
```

### G. FLOOR(x) & CEIL(x) / CEILING(x)
*   **`FLOOR(x)`**: Rounds **down** to the next lowest integer.
*   **`CEIL(x)`**: Rounds **up** to the next highest integer.
```sql
SELECT FLOOR(4.7); -- Output: 4
SELECT CEIL(4.3);  -- Output: 5
```

### H. SQRT(x) & POW(x, y) / POWER(x, y)
*   **`SQRT(x)`**: Square root of a number.
*   **`POW(x, y)`**: Raises `x` to the power `y`.
```sql
SELECT SQRT(25);   -- Output: 5
SELECT POW(2, 3);  -- Output: 8
```

### I. RAND()
Generates a random floating-point number between `0` (inclusive) and `1` (exclusive).
*   **Real-time Use:** Random lottery draws, picking a random winner.
```sql
-- Select 1 random order from a table
SELECT * FROM Orders ORDER BY RAND() LIMIT 1;
```

### J. PI() & EXP(x)
*   **`PI()`**: Returns the value of $\pi$ (~3.141593).
*   **`EXP(x)`**: Returns $e^x$.
```sql
SELECT PI();    -- Output: 3.141593
SELECT EXP(1);  -- Output: 2.718282
```

## ⚙️ 2. Low-Level Bitwise Operators

Bitwise operators manipulate data at the binary level (bits: 0s and 1s). While rarely used in everyday business dashboards, they are common in high-performance networking, file systems, and hardware integrations.

| Operator | Description | Example | Binary Calculation | Output |
| :--- | :--- | :--- | :--- | :--- |
| **`&`** | Bitwise AND | `SELECT 5 & 3;` | `0101 & 0011 = 0001` | 1 |
| **`\|`** | Bitwise OR | `SELECT 5 \| 3;` | `0101 \| 0011 = 0111` | 7 |
| **`^`** | Bitwise XOR | `SELECT 5 ^ 3;` | `0101 ^ 0011 = 0110` | 6 |
| **`<<`** | Shift Left (Multiply by $2^n$) | `SELECT 5 << 1;` | Shift bits of `5` (0101) left by 1 | 10 |
| **`>>`** | Shift Right (Divide by $2^n$) | `SELECT 5 >> 1;` | Shift bits of `5` (0101) right by 1 | 2 |

## 🔤 3. String Functions (Restored & Completed)

String scalar functions allow you to transform, slice, and inspect text data in MySQL.

### A. CONCAT(str1, str2, ...) & CONCAT_WS(separator, str1, str2, ...)
*   **`CONCAT()`**: Merges multiple text strings together. If any input is `NULL`, the output is `NULL`.
    ```sql
    SELECT CONCAT('Raju', ' ', 'Sharma') AS full_name; -- Output: 'Raju Sharma'
    ```
*   **`CONCAT_WS()`**: (Concat With Separator). First argument is the separator, which joins the rest of the arguments.
    ```sql
    SELECT CONCAT_WS('-', '2026', '07', '25') AS date_str; -- Output: '2026-07-25'
    ```

### B. LENGTH(str) & CHAR_LENGTH(str)
*   **`LENGTH()`**: Returns the length of the string in **bytes**.
*   **`CHAR_LENGTH()`**: Returns the length of the string in **characters**.
    ```sql
    -- For standard ASCII strings, both are same:
    SELECT LENGTH('Cat'), CHAR_LENGTH('Cat'); -- Output: 3, 3
    ```

### C. UPPER(str) / UCASE(str) & LOWER(str) / LCASE(str)
Converts text cases.
```sql
SELECT UPPER('mysql'); -- Output: 'MYSQL'
SELECT LOWER('MYSQL'); -- Output: 'mysql'
```

### D. SUBSTRING(str, pos, len) / SUBSTR(str, pos, len)
Extracts a part of a string starting from position `pos` (1-indexed) for `len` characters. If `len` is omitted, it extracts to the end.
```sql
SELECT SUBSTRING('Database', 1, 4); -- Output: 'Data' (extracts 4 chars starting from index 1)
SELECT SUBSTRING('Database', 5);    -- Output: 'base'
```

### E. REPLACE(str, from_str, to_str)
Replaces all occurrences of `from_str` with `to_str` in a text.
```sql
SELECT REPLACE('I love SQL Server', 'SQL Server', 'MySQL'); -- Output: 'I love MySQL'
```

### F. TRIM(str) / LTRIM(str) / RTRIM(str)
Removes leading and trailing white spaces.
```sql
SELECT TRIM('  hello  '); -- Output: 'hello'
SELECT LTRIM('  hi');     -- Output: 'hi'
SELECT RTRIM('bye  ');    -- Output: 'bye'
```

### G. INSTR(str, substr) & LOCATE(substr, str, [pos])
Finds the position of a substring in a string (1-indexed).
*   **`INSTR(str, substr)`**: Returns position of first occurrence.
    ```sql
    SELECT INSTR('MySQL', 'SQL'); -- Output: 3
    ```
*   **`LOCATE(substr, str, [pos])`**: Similar to `INSTR`, but supports an optional starting search position `pos`.
    ```sql
    SELECT LOCATE('in', 'jani') AS result; -- Output: 0 (not found)
    SELECT LOCATE('SQL', 'MySQL Database'); -- Output: 3
    ```

### H. LEFT(str, len) & RIGHT(str, len)
Slices a specified number of characters from the left or right of a string.
```sql
SELECT LEFT('Masterclass', 6);  -- Output: 'Master'
SELECT RIGHT('Masterclass', 5); -- Output: 'class'
```

### I. ASCII(str) & ORD(str) & CHAR(x)
*   **`ASCII()`**: Returns the ASCII numeric value of the first character of the string.
    ```sql
    SELECT ASCII('A'); -- Output: 65
    ```
*   **`ORD()`**: Returns the Unicode/ASCII code value of the first character.
    ```sql
    SELECT ORD('A');   -- Output: 65
    ```
*   **`CHAR()`**: Returns the character corresponding to the given ASCII/code values.
    ```sql
    SELECT CHAR(65);   -- Output: 'A'
    ```


### J. FORMAT(num, decimals)
Formats a number with commas and rounds to the specified decimal places, returning it as a string.
```sql
SELECT FORMAT(12345.6789, 2); -- Output: '12,345.68'
SELECT FORMAT(12000.676, 4);  -- Output: '12,000.6760'
```

### K. REPEAT(str, count) & REVERSE(str)
*   **`REPEAT()`**: Repeats a string a specified number of times.
    ```sql
    SELECT REPEAT('SQL', 3); -- Output: 'SQLSQLSQL'
    ```
*   **`REVERSE()`**: Reverses the character order.
    ```sql
    SELECT REVERSE('MySQL'); -- Output: 'LQSyM'
    ```

### L. SPACE(count)
Returns a string consisting of the specified number of spaces.
```sql
SELECT CONCAT('My', SPACE(3), 'SQL'); -- Output: 'My   SQL'
```

### M. INSERT(str, pos, len, new_str)
Inserts a string `new_str` at position `pos` (starting from 1), replacing `len` characters.
```sql
SELECT INSERT('Database', 2, 3, 'XX'); -- Output: 'DXXbase'
SELECT INSERT('janibasha', 9, 3, 'hello'); -- Output: 'janibashhello' (since length exceeds)
```

## 🖥️ 4. System Information Functions

These functions provide metadata about the database environment, user sessions, and MySQL version.

### A. DATABASE()
Returns the name of the active database for the current connection. Returns `NULL` if no database is selected.
```sql
SELECT DATABASE(); -- Output: 'CompanyDB' (or active DB name)
```

### B. USER()
Returns the current MySQL username and host name used for authentication.
```sql
SELECT USER(); -- Output: 'root@localhost'
```

### D. CONNECTION_ID()
Returns the unique thread ID for the current MySQL connection.
```sql
SELECT CONNECTION_ID(); -- Output: 14 (varies per connection)
```

## 📅 5. Date & Time Advanced Functions

Beyond standard date extraction (`YEAR`, `MONTH`, `DAY`, `DAYNAME`), MySQL provides advanced date arithmetic and conversion functions:

### A. TIMESTAMPDIFF(unit, datetime1, datetime2)
Returns the difference between two date/datetime expressions in specified units (`YEAR`, `MONTH`, `DAY`, `HOUR`, `MINUTE`, `SECOND`).
```sql
-- Calculate age of a person born on 1995-07-20:
SELECT TIMESTAMPDIFF(YEAR, '1995-07-20', CURDATE()) AS age_in_years;

-- Calculate difference in minutes:
SELECT TIMESTAMPDIFF(MINUTE, '2026-08-06 10:00:00', '2026-08-06 15:30:00'); -- Output: 330
```

### B. SEC_TO_TIME(seconds) & TIME_TO_SEC(time)
* **`SEC_TO_TIME(seconds)`**: Converts numeric seconds into `HH:MM:SS` format.
    ```sql
    SELECT SEC_TO_TIME(3665); -- Output: '01:01:05'
    ```
* **`TIME_TO_SEC(time)`**: Converts time/datetime into total seconds.
    ```sql
    SELECT TIME_TO_SEC('01:01:05'); -- Output: 3665
    ```

### C. LAST_DAY(date)
Returns the last day of the month for the given date value.
```sql
SELECT LAST_DAY('2026-02-15'); -- Output: '2026-02-28'
SELECT LAST_DAY(NOW());         -- Output: Last date of current month
```

### D. WEEKOFYEAR(date) & DAYOFWEEK(date)
* **`WEEKOFYEAR(date)`**: Returns the calendar week number (1 to 53) of the year.
    ```sql
    SELECT WEEKOFYEAR('2026-08-06'); -- Output: 32
    ```
* **`DAYOFWEEK(date)`**: Returns day index (1 = Sunday, 2 = Monday, ..., 7 = Saturday).
    ```sql
    SELECT DAYOFWEEK('2026-08-06'); -- Output: 5 (Thursday)
    ```

## 🧠 6. Advanced & Conditional Control Flow Functions


These functions add logical conditional execution, type conversions, and null-handling mechanics directly into SQL queries.

### A. CASE WHEN (Inline IF-ELSE Logic)
Works like a program's `if-else` block. It evaluates a list of conditions and returns a corresponding value.

#### Example 1: Grouping employee salaries
```sql
SELECT name, salary,
   CASE 
     WHEN salary > 50000 THEN 'High'
     WHEN salary > 30000 THEN 'Medium'
     ELSE 'Low'
   END AS Salary_Level
FROM Employee;
```

#### Example 2: Classifying product prices
```sql
SELECT pname, pprice,
   CASE 
     WHEN pprice > 50000 THEN 'high' 
     WHEN pprice > 11000 THEN 'medium' 
     ELSE 'low' 
   END AS level_salaries 
FROM products;
```
*   **Result Set Table:**
    | pname | pprice | level_salaries |
    | :--- | :--- | :--- |
    | mobile | 10000.90 | low |
    | watch | 12001.00 | medium |
    | buds | NULL | low |
    | bike | 78787.99 | high |
    | bike | 78787.99 | high |
    | bike | NULL | low |


### B. IF(condition, value_if_true, value_if_false)
An inline ternary operator. If the first expression evaluates to true (not 0 and not NULL), it returns the second expression; otherwise, it returns the third expression.
```sql
SELECT IF(10 > 5, 'Yes', 'No'); -- Output: 'Yes'
```

### C. IFNULL(expression, alt_value) & ISNULL(expression)
*   **`IFNULL()`**: Returns the first argument if it is not `NULL`; otherwise, returns the alternative value.
    ```sql
    SELECT IFNULL(NULL, 'Default'); -- Output: 'Default'
    SELECT IFNULL('hello', 'Default'); -- Output: 'hello'
    ```
*   **`ISNULL()`**: Returns `1` if the expression is `NULL`; otherwise, returns `0`.
    ```sql
    SELECT ISNULL(NULL);   -- Output: 1
    SELECT ISNULL('abc');  -- Output: 0
    ```

### D. COALESCE(val1, val2, ..., valN)
Returns the first non-`NULL` value in the argument list.
```sql
SELECT COALESCE(NULL, NULL, 'Hello', 'World'); -- Output: 'Hello'
```

### E. NULLIF(expr1, expr2)
Returns `NULL` if both arguments are equal; otherwise, it returns the first argument.
```sql
SELECT NULLIF(10, 10); -- Output: NULL
SELECT NULLIF(10, 20); -- Output: 10
```

### F. CAST(expression AS data_type)
Converts a value from its current data type to a target data type (such as `UNSIGNED`, `SIGNED`, `DECIMAL`, `CHAR`, `DATE`, etc.).
```sql
SELECT CAST('123' AS UNSIGNED) AS number_val; -- Output: 123
```

### N. LPAD(str, len, padstr) & RPAD(str, len, padstr)
Pads a string on the left (`LPAD`) or right (`RPAD`) with another string up to a specified length `len`.
```sql
SELECT LPAD('123', 5, '0'); -- Output: '00123'
SELECT RPAD('Code', 7, '!'); -- Output: 'Code!!!'
```

## 🧭 6. Date and Time Functions

Date and Time functions in MySQL allow you to extract, format, calculate, and compare date and time values.

### A. Current Date & Time Functions
| Function | Description | Example | Output |
| :--- | :--- | :--- | :--- |
| **`NOW()`** | Returns current date and time | `SELECT NOW();` | `2026-08-06 14:30:15` |
| **`CURDATE()`** / **`CURRENT_DATE()`** | Returns current date only | `SELECT CURDATE();` | `2026-08-06` |
| **`CURTIME()`** / **`CURRENT_TIME()`** | Returns current time only | `SELECT CURTIME();` | `14:30:15` |
| **`UTC_DATE()`** / **`UTC_TIME()`** | Returns current date/time in UTC | `SELECT UTC_DATE();` | `2026-08-06` |

### B. Date Part Extraction Functions
| Function | Description | Example | Output |
| :--- | :--- | :--- | :--- |
| **`YEAR(date)`** | Extracts year | `SELECT YEAR('2026-08-06');` | `2026` |
| **`MONTH(date)`** | Extracts month (1–12) | `SELECT MONTH('2026-08-06');` | `8` |
| **`DAY(date)`** / **`DAYOFMONTH(date)`** | Extracts day of month | `SELECT DAY('2026-08-06');` | `6` |
| **`HOUR(time)`** | Extracts hour | `SELECT HOUR('14:30:15');` | `14` |
| **`MINUTE(time)`** | Extracts minute | `SELECT MINUTE('14:30:15');` | `30` |
| **`SECOND(time)`** | Extracts second | `SELECT SECOND('14:30:15');` | `15` |
| **`DAYNAME(date)`** | Returns weekday name | `SELECT DAYNAME('2026-08-06');` | `Thursday` |
| **`MONTHNAME(date)`** | Returns month name | `SELECT MONTHNAME('2026-08-06');` | `August` |
| **`DAYOFWEEK(date)`** | Returns 1 (Sun)–7 (Sat) | `SELECT DAYOFWEEK('2026-08-06');` | `5` |
| **`QUARTER(date)`** | Returns quarter (1–4) | `SELECT QUARTER('2026-08-06');` | `3` |
| **`EXTRACT(unit FROM date)`** | Extracts specific date part | `SELECT EXTRACT(MONTH FROM '2026-08-06');` | `8` |

### C. Date & Time Arithmetic
```sql
-- Add 5 days to current date
SELECT NOW() + INTERVAL 5 DAY;

-- Subtract 2 months from a specific date
SELECT DATE_SUB('2026-08-06', INTERVAL 2 MONTH); -- Output: '2026-06-06'

-- Difference in days between two dates
SELECT DATEDIFF('2026-12-31', '2026-08-06'); -- Output: 147

-- Difference in specific units (YEAR, MONTH, DAY, HOUR, MINUTE)
SELECT TIMESTAMPDIFF(YEAR, '1995-07-20', CURDATE()) AS age;
```

### D. Date & Time Formatting
| Function | Description | Example | Output |
| :--- | :--- | :--- | :--- |
| **`DATE_FORMAT(date, format)`** | Formats date using specifiers | `SELECT DATE_FORMAT('2026-08-06', '%d-%m-%Y');` | `06-08-2026` |
| **`TIME_FORMAT(time, format)`** | Formats time using specifiers | `SELECT TIME_FORMAT('14:30:15', '%h:%i %p');` | `02:30 PM` |
| **`STR_TO_DATE(str, format)`** | Converts text string to DATE | `SELECT STR_TO_DATE('06/08/2026', '%d/%m/%Y');` | `2026-08-06` |

#### Common Date Format Specifiers:
- `%Y`: 4-digit Year (`2026`) | `%y`: 2-digit Year (`26`)
- `%m`: Month number (`08`) | `%M`: Month name (`August`)
- `%d`: Day of month (`06`) | `%W`: Weekday name (`Thursday`)
- `%H`: Hour 00–23 | `%h`: Hour 01–12 | `%i`: Minutes | `%s`: Seconds | `%p`: AM/PM

### E. Practical Date Queries & Challenges
```sql
-- 1. Find employees who joined in the current year
SELECT name, hire_date FROM employees WHERE YEAR(hire_date) = YEAR(CURDATE());

-- 2. Find employees who joined in the last 30 days
SELECT name FROM employees WHERE hire_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY);

-- 3. Get the first and last day of the current month
SELECT DATE_FORMAT(NOW(), '%Y-%m-01') AS first_day, LAST_DAY(NOW()) AS last_day;
```
