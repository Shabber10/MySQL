# Day 03: Chapter 2 — Grouping Data with GROUP BY

Often, we do not want to summarize an entire table into a single row. Instead, we want to group rows that share a common attribute and calculate summaries for each group. This is achieved using the **`GROUP BY`** clause.

---

## 🧱 What is `GROUP BY`?

The `GROUP BY` clause groups rows that have the same values in specified columns into summary rows (like "find the number of customers in each city").

### How it works internally:
1.  **Split**: Rows are split into temporary buckets based on the grouping column's values.
2.  **Apply**: The aggregate function is run on each bucket separately.
3.  **Combine**: The summary result for each bucket is combined into the final output table.

---

## 🔍 Examples using the `Sales` Table

We will use the following example table:
*   `Sales (id, customer_name, product, quantity, price, city)`

### Example 1: Total sales amount per product
```sql
SELECT product, SUM(price * quantity) AS total_sales
FROM Sales
GROUP BY product;
```
*   **Result**: Groups all sales by `product` (e.g., 'Laptop', 'Mobile', 'Tablet') and displays the sum of purchase amount for each.

### Example 2: Count the number of orders in each city
```sql
SELECT city, COUNT(*) AS total_orders
FROM Sales
GROUP BY city;
```
*   **Result**: Displays the number of sales transactions that occurred in 'Delhi', 'Mumbai', 'Chennai', and 'Hyderabad'.

### Example 3: Average price of each product
```sql
SELECT product, AVG(price) AS average_price
FROM Sales
GROUP BY product;
```
*   **Result**: Shows the average unit price for each product category.

---

## 🔀 Grouping by Multiple Columns

You can group by more than one column. MySQL will create a group for every unique *combination* of values in those columns.

```sql
-- Find total quantity sold of each product in each city
SELECT city, product, SUM(quantity) AS total_qty
FROM Sales
GROUP BY city, product;
```

## 📊 Generating Subtotals & Grand Totals: `WITH ROLLUP`

The `WITH ROLLUP` modifier is used with `GROUP BY` to generate summary rows that display **subtotals** and **grand totals** for aggregated data.

### Syntax:
```sql
SELECT column1, column2, SUM(aggregate_col)
FROM table_name
GROUP BY column1, column2 WITH ROLLUP;
```

### Example:
```sql
-- Calculate total sales per city and product, plus subtotals per city and grand total:
SELECT city, product, SUM(quantity) AS total_qty
FROM Sales
GROUP BY city, product WITH ROLLUP;
```
*   **How it works:** MySQL produces extra rows where `product` is `NULL` (subtotal for that city) and a final row where both `city` and `product` are `NULL` (grand total across all cities).

---

## ⚠️ Important Rules for `GROUP BY`
1.  **Non-aggregated Columns:** Any column in your `SELECT` list that is **not** wrapped inside an aggregate function (like `COUNT`, `SUM`, `AVG`) **must** be listed in the `GROUP BY` clause.
    *   *Invalid:* `SELECT name, city, SUM(marks) FROM students GROUP BY city;` (since `name` is in `SELECT` but not in `GROUP BY`).
2.  **Order of Clauses:** The `GROUP BY` clause must come **after** the `WHERE` clause, **before** `HAVING`, and **before** `ORDER BY`.
