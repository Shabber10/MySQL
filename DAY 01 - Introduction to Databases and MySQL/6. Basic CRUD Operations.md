# Day 01: Basic CRUD Operations

CRUD is an acronym for **Create, Read, Update, and Delete**—the four basic functions of persistent storage. In SQL, these map directly to the DML (Data Manipulation Language) and DQL (Data Query Language) statements.

We will use the `students` table created in the previous file to demonstrate these operations.

---

## 1. CREATE (Insert Data)

To add new records to a table, we use the `INSERT INTO` statement.

### Method A: Inserting a single row (specifying column names)
```sql
INSERT INTO students (first_name, last_name, email, enrollment_date)
VALUES ('John', 'Doe', 'john.doe@email.com', '2026-09-01');
```
*Note: Because `student_id` is `AUTO_INCREMENT` and `status` has a `DEFAULT` value, we do not need to provide them in our INSERT statement.*

### Method B: Inserting multiple rows in one command
```sql
INSERT INTO students (first_name, last_name, email, enrollment_date, status)
VALUES 
('Jane', 'Smith', 'jane.smith@email.com', '2026-09-01', 'Active'),
('Alice', 'Johnson', 'alice.j@email.com', '2026-09-02', 'Inactive'),
('Bob', 'Williams', 'bob.w@email.com', '2026-09-03', 'Active');
```

---

## 2. READ (Query Data)

To retrieve records from a table, we use the `SELECT` statement.

### Retrieve all columns and all rows:
```sql
SELECT * FROM students;
```
*(The `*` symbol is a wildcard that represents all columns).*

### Retrieve specific columns:
```sql
SELECT first_name, email FROM students;
```

### Filtering results with the `WHERE` clause:
```sql
-- Get students whose status is Active
SELECT * FROM students 
WHERE status = 'Active';

-- Get students enrolled on or after a specific date
SELECT * FROM students 
WHERE enrollment_date >= '2026-09-02';
```

---

## 3. UPDATE (Modify Data)

To modify existing records, we use the `UPDATE` statement.

> [!WARNING]
> Always check your `WHERE` clause when executing `UPDATE` or `DELETE` statements. If you omit the `WHERE` clause, **every single row** in the table will be updated!

### Update a single record:
```sql
UPDATE students
SET status = 'Active'
WHERE student_id = 3;
```

### Update multiple records (using IN):
```sql
UPDATE students
SET status = 'Active'
WHERE student_id IN (1, 3);
```

> [!CAUTION]
> **Common Syntax Error:** Beginners often try to filter multiple records by separating them with commas in a standard equality filter (e.g., `WHERE student_id = 1, 3;`). **This is invalid syntax and will fail.** You must use the `IN` operator as shown above.

### Update multiple columns:
```sql
UPDATE students
SET status = 'Inactive', email = 'john.doe.new@email.com'
WHERE student_id = 1;
```

### Method C: Copying Records from Another Table (`INSERT INTO ... SELECT`)
You can copy rows directly from a source table into a destination table using `INSERT INTO ... SELECT`:

```sql
-- Copy matching columns from students table into students_archive
INSERT INTO students_archive (first_name, last_name, email, enrollment_date)
SELECT first_name, last_name, email, enrollment_date
FROM students
WHERE status = 'Inactive';
```

### ⚠️ Common Error: Column Count Mismatch (`ERROR 1136`)
If you try to insert into all columns without listing specific column names, you **must** provide a value for every single column in exact order.

```sql
-- FAILS if the table has 4 columns and you only provide 3 values:
INSERT INTO students VALUES ('Raju', 23, 76);
-- Output: ERROR 1136 (21S01): Column count doesn't match value count at row 1
```

---

## 4. DELETE (Remove Data)

To remove existing records, we use the `DELETE` statement.

> [!WARNING]
> Like `UPDATE`, if you omit the `WHERE` clause, **all rows** from the table will be deleted.

### Delete a specific record:
```sql
DELETE FROM students
WHERE student_id = 4;
```

### Delete all records but keep table structure:
```sql
DELETE FROM students;
```

---

## 📊 Summary Comparison: DELETE vs. TRUNCATE

| Feature | DELETE ❌ | TRUNCATE 🧹 |
| :--- | :--- | :--- |
| **Command Category** | **DML** (Data Manipulation Language) | **DDL** (Data Definition Language) |
| **Operation** | Removes specific rows or all rows | Removes **all** rows at once |
| **WHERE Clause** | ✅ Supported (`WHERE id = 5`) | ❌ **Not Supported** (Fails with Error 1064) |
| **Execution Method** | Deletes rows individually (Row-by-row) | Drops and recreates table / resets data pages |
| **Speed / Efficiency** | Slower on large datasets | **Extremely Fast** |
| **AUTO_INCREMENT** | Keeps current auto-increment counter | **Resets** auto-increment counter back to 1 |
| **Transaction Rollback** | Can be rolled back (before `COMMIT`) | Auto-committed in MySQL (cannot be rolled back) |
| **Table Structure** | Table structure remains intact | Table structure remains intact |
