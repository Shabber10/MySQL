# Day 01: MySQL Installation and Command Line

Before we can start writing SQL queries, you need to know how to access the MySQL server and interact with it. This file explains how to install/access MySQL and how to use the Command Line Interface (CLI) or GUI tools.

---

## 1. Connection Overview

To work with MySQL locally, you typically need two components:
1.  **MySQL Server:** The background service that manages databases, stores tables, and processes SQL queries.
2.  **MySQL Client:** A program (CLI or GUI) that connects to the server and allows you to run queries.

### Popular Client Tools:
*   **MySQL Command-Line Client (CLI):** The standard, lightweight terminal tool that comes built-in with MySQL Server.
*   **MySQL Workbench:** An official, free GUI tool by Oracle for database management.
*   **DBeaver / TablePlus / VS Code extensions:** Popular third-party database managers.

---

## 2. Connecting to MySQL via Command Line

Once MySQL Server is installed and running, you can connect to it using the Command Prompt (Windows) or Terminal (macOS/Linux).

### Connection Command:
```bash
mysql -u root -p
```

### Explaining the parameters:
*   `-u root`: Specifies the user you want to log in as. `root` is the default administrative superuser.
*   `-p`: Prompts you for the password. (After hitting Enter, type your password. Note that no characters or asterisks will display as you type for security reasons).

If you are connecting to a remote server or a specific port:
```bash
mysql -h localhost -P 3306 -u root -p
```
*   `-h localhost`: Hostname or IP address of the MySQL server.
*   `-P 3306`: The port number (3306 is the default port for MySQL).

To exit the MySQL prompt, type:
```sql
exit;
```
or
```sql
quit;
```

---

## 3. Basic Administrative Commands

Once logged into the MySQL CLI prompt (`mysql>`), you can run basic diagnostic commands. 

> [!IMPORTANT]
> Every SQL command in the MySQL Command-Line Client must end with a semicolon (`;`). If you press Enter without a semicolon, MySQL will think the command is continuing and display a `->` prompt on the next line.

### Check Current Version and Status:
```sql
SELECT VERSION();
```

### List Available Databases:
```sql
SHOW DATABASES;
```

### Check Currently Active Database:
```sql
SELECT DATABASE();
```
*(If no database is selected, this will return `NULL`).*

### Check Current User:
```sql
SELECT USER();
```
