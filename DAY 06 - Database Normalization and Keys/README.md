# DAY 06: Database Normalization & Keys

This directory contains the curriculum, practice exercises, and scripts for **Database Normalization & Keys**.

---

## 📚 Chapters & Content Outline

*   **[1. Database Keys and Integrity](1.%20Database%20Keys%20and%20Integrity.md)** - Master database keys. Learn the definitions of Super Keys, Candidate Keys, Primary Keys, Foreign Keys, Unique Keys, and study Entity and Referential Integrity rules.
*   **[2. Database Normalization - 1NF, 2NF, 3NF](2.%20Database%20Normalization%20-%201NF%2c%202NF%2c%203NF.md)** - Learn how to eliminate database anomalies (Insertion, Update, Deletion) and decompose relations step-by-step into 1st, 2nd, and 3rd Normal Forms.
*   **[3. Day 6 Hands-on Practice and Exercises](3.%20Day%206%20Hands-on%20Practice%20and%20Exercises.md)** - Practice normalizing unnormalized spreadsheet data into fully relational, normalized schemas.
*   **[day6_practice_script.sql](day6_practice_script.sql)** - Executable SQL script demonstrating data anomalies in an unnormalized table and creating a clean 3NF database layout.
