### 🟢 Aggregation and Grouping Exercises

#### Q1. List all customers along with their total purchase amount (quantity × price) in descending order of total purchase.
*   **Query:**
    ```sql
    SELECT customer_name, (quantity * price) AS total_purchase
    FROM Sales
    ORDER BY total_purchase DESC;
    ```
*   **Expected Output:**
    | customer_name | total_purchase |
    | :--- | :--- |
    | Frank | 100000.00 |
    | Charlie | 52000.00 |
    | Alice | 50000.00 |
    | David | 36000.00 |
    | Bob | 30000.00 |
    | Eve | 15000.00 |
    | Grace | 12000.00 |

#### Q2. Find the total quantity of 'Mobile' sold in Mumbai.
*   **Query:**
    ```sql
    SELECT SUM(quantity) AS total_mobiles_sold
    FROM Sales
    WHERE product = 'Mobile' AND city = 'Mumbai';
    ```
*   **Expected Output:**
    | total_mobiles_sold |
    | :--- |
    | 3 |

#### Q3. Find the total quantity of each product sold, but only include products with more than 2 items sold, and display them in descending order of quantity.
*   **Query:**
    ```sql
    SELECT product, SUM(quantity) AS total_quantity
    FROM Sales
    GROUP BY product
    HAVING total_quantity > 2
    ORDER BY total_quantity DESC;
    ```
*   **Expected Output:**
    | product | total_quantity |
    | :--- | :--- |
    | Laptop | 4 |
    | Tablet | 4 |
    | Mobile | 3 |

#### Q4. Find the total quantity of 'Tablet' sold in Chennai and display only if more than 2 tablets were sold.
*   **Query:**
    ```sql
    SELECT city, product, SUM(quantity) AS total_qty
    FROM Sales
    WHERE product = 'Tablet' AND city = 'Chennai'
    GROUP BY city, product
    HAVING total_qty > 2;
    ```
*   **Expected Output:**
    | city | product | total_qty |
    | :--- | :--- | :--- |
    | Chennai | Tablet | 4 |

## 🎯 Day 02 Recap: Logical Negation (`NOT` Operators)

We will use the following `students` table:

```sql
CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    marks INT,
    city VARCHAR(50)
);

INSERT INTO students VALUES
(1, 'Amit', 18, 85, 'Delhi'),
(2, 'Sara', 19, 72, 'Mumbai'),
(3, 'John', 18, 90, 'Delhi'),
(4, 'Ravi', 20, 60, 'Chennai'),
(5, 'Meena', 21, 50, 'Hyderabad');
```

#### Q1. Display students who are NOT from Delhi.
*   **Query:**
    ```sql
    SELECT name, city FROM students WHERE NOT city = 'Delhi';
    ```
*   **Output:** Sara (Mumbai), Ravi (Chennai), Meena (Hyderabad).

#### Q2. Display students who are NOT in Delhi or Mumbai.
*   **Query:**
    ```sql
    SELECT name, city FROM students WHERE city NOT IN ('Delhi', 'Mumbai');
    ```
*   **Output:** Ravi (Chennai), Meena (Hyderabad).

#### Q3. Display students whose names DO NOT start with 'A'.
*   **Query:**
    ```sql
    SELECT name FROM students WHERE name NOT LIKE 'A%';
    ```
*   **Output:** Sara, John, Ravi, Meena.

#### Q4. Display students whose marks are NOT BETWEEN 60 and 90.
*   **Query:**
    ```sql
    SELECT name, marks FROM students WHERE marks NOT BETWEEN 60 AND 90;
    ```
*   **Output:** Meena (50).

## 🎯 Practice Scenario 3: 15 Math Functions Interview Q&As

### Q1. How do you find the absolute salary difference between two values?
*   **Expected Thinking:** Use the `ABS()` function to discard any negative signs.
```sql
SELECT ABS(5000 - 7200) AS diff; -- Output: 2200
```

### Q2. How do you find the number of full boxes needed if 105 items are packed in boxes of 10?
*   **Expected Thinking:** Use integer division `DIV` to ignore the remainder.
```sql
SELECT 105 DIV 10 AS boxes; -- Output: 10
```

### Q3. How do you find the leftover items after packing the boxes in Q2?
*   **Expected Thinking:** Use modulo division `MOD()` to get the remainder.
```sql
SELECT MOD(105, 10) AS leftover; -- Output: 5
```

### Q4. How do you round a product price of 456.789 to 2 decimal places?
*   **Expected Thinking:** Use `ROUND(x, d)` where `d = 2`.
```sql
SELECT ROUND(456.789, 2) AS rounded_price; -- Output: 456.79
```

### Q5. How do you remove decimals of 456.789 without rounding?
*   **Expected Thinking:** Use `TRUNCATE(x, d)` to truncate instead of rounding.
```sql
SELECT TRUNCATE(456.789, 2) AS truncated_price; -- Output: 456.78
```

### Q6. How do you get the highest value among 450, 600, and 300?
*   **Expected Thinking:** Use `GREATEST(x1, x2, ...)` for comparing in-row list values.
```sql
SELECT GREATEST(450, 600, 300) AS max_val; -- Output: 600
```

### Q7. How do you get the lowest value among 450, 600, and 300?
*   **Expected Thinking:** Use `LEAST(x1, x2, ...)` to find the smallest list value.
```sql
SELECT LEAST(450, 600, 300) AS min_val; -- Output: 300
```

### Q8. How do you calculate the square root of an area value of 144?
*   **Expected Thinking:** Use `SQRT()` for square root calculations.
```sql
SELECT SQRT(144) AS side_length; -- Output: 12
```

### Q9. How do you calculate $2^5$ in MySQL?
*   **Expected Thinking:** Use `POW(base, exponent)` or `POWER()`.
```sql
SELECT POW(2, 5) AS power_calc; -- Output: 32
```

### Q10. How do you round ratings to the nearest integer?
*   **Expected Thinking:** Use `ROUND(x)` without a second parameter.
```sql
SELECT ROUND(4.6) AS rounded_rating; -- Output: 5
```

### Q11. How do you fetch a random record from a table?
*   **Expected Thinking:** Sort the table dynamically by `RAND()` and select the top 1 row.
```sql
SELECT * FROM Sales ORDER BY RAND() LIMIT 1;
```

### Q12. How do you find the next highest integer value of a price of 499.1?
*   **Expected Thinking:** Use `CEIL()` or `CEILING()` to round up.
```sql
SELECT CEIL(499.1) AS ceiling_val; -- Output: 500
```

### Q13. How do you find the lower integer value of a price of 499.9?
*   **Expected Thinking:** Use `FLOOR()` to round down.
```sql
SELECT FLOOR(499.9) AS floor_val; -- Output: 499
```

### Q14. How do you calculate the exponential growth of $e^2$?
*   **Expected Thinking:** Use `EXP(2)`.
```sql
SELECT EXP(2) AS exp_growth; -- Output: 7.389056
```

### Q15. How do you calculate the final bill amount (amount - discount) rounded to 2 decimals?
*   **Expected Thinking:** Subtract columns, then wrap in `ROUND(val, 2)`.
```sql
SELECT ROUND(amount - discount, 2) AS final_bill FROM Orders;
```

## 🔤 Practice Scenario 4: 20 String and Advanced Functions Exercises

This section provides quick practice exercises and solutions for validating string manipulation, system metadata, and advanced control flow functions in MySQL.

### 1. UPPER() and LOWER()

#### Q1. Write a query to display the string 'hello world' in uppercase.
```sql
SELECT UPPER('hello world') AS result;
-- Output: 'HELLO WORLD'
```

#### Q2. Convert 'MYSQL Functions' into lowercase.
```sql
SELECT LOWER('MYSQL Functions') AS result;
-- Output: 'mysql functions'
```

### 2. LENGTH() and CHAR_LENGTH()

#### Q3. Find the length of the string 'Database'.
```sql
SELECT LENGTH('Database') AS result;
-- Output: 8
```

#### Q4. What is the length (in characters) of the string 'My SQL'?
```sql
SELECT CHAR_LENGTH('My SQL') AS result;
-- Output: 6
```

### 3. CONCAT() and CONCAT_WS()

#### Q5. Concatenate 'My' and 'SQL' into one string.
```sql
SELECT CONCAT('My', 'SQL') AS result;
-- Output: 'MySQL'
```

#### Q6. Combine first name 'John' and last name 'Doe' with a space in between.
```sql
SELECT CONCAT('John', ' ', 'Doe') AS full_name;
-- Output: 'John Doe'
```

### 4. SUBSTRING()

#### Q7. Extract the first 4 characters from 'Database'.
```sql
SELECT SUBSTRING('Database', 1, 4) AS result;
-- Output: 'Data'
```

#### Q8. Extract characters from position 3 to 6 from 'Functions'.
```sql
-- Starting at 3, extract 4 characters (positions 3, 4, 5, 6)
SELECT SUBSTRING('Functions', 3, 4) AS result;
-- Output: 'ncti'
```

### 5. TRIM(), LTRIM(), and RTRIM()

#### Q9. Remove spaces from both sides of ' SQL '.
```sql
SELECT TRIM(' SQL ') AS result;
-- Output: 'SQL'
```

#### Q10. Remove only left-side spaces from ' MySQL'.
```sql
SELECT LTRIM(' MySQL') AS result;
-- Output: 'MySQL'
```

#### Q11. Remove only right-side spaces from 'Hello '.
```sql
SELECT RTRIM('Hello ') AS result;
-- Output: 'Hello'
```

### 6. REPLACE()

#### Q12. Replace 'Java' with 'SQL' in the string 'I like Java'.
```sql
SELECT REPLACE('I like Java', 'Java', 'SQL') AS result;
-- Output: 'I like SQL'
```

#### Q13. Change 'Good Morning' into 'Good Evening'.
```sql
SELECT REPLACE('Good Morning', 'Morning', 'Evening') AS result;
-- Output: 'Good Evening'
```

### 7. INSERT()

#### Q14. Insert 'XX' into 'Database' starting from position 2, replacing 3 characters.
```sql
SELECT INSERT('Database', 2, 3, 'XX') AS result;
-- Output: 'DXXbase'
```

#### Q15. Replace 2 characters from position 4 in 'Learning' with 'SQL'.
```sql
SELECT INSERT('Learning', 4, 2, 'SQL') AS result;
-- Output: 'LeaSQLning'
```

### 8. REVERSE() & REPEAT()

#### Q16. Reverse the string 'MySQL'.
```sql
SELECT REVERSE('MySQL') AS result;
-- Output: 'LQSyM'
```

#### Q17. Repeat the string 'Raju' 3 times.
```sql
SELECT REPEAT('Raju', 3) AS result;
-- Output: 'rajurajuraju'
```

### 9. LOCATE() and INSTR()

#### Q18. Find the position of 'SQL' in the string 'I am learning SQL'.
```sql
SELECT LOCATE('SQL', 'I am learning SQL') AS result;
-- Output: 15
```

#### Q19. Find the position of 'a' in the string 'Database'.
```sql
SELECT INSTR('Database', 'a') AS result;
-- Output: 2 (returns first occurrence)
```

### 10. Advanced Conditional & System Functions

#### Q20. Force a case-sensitive comparison of 'abc' and 'ABC', and check if they match.
```sql
SELECT 'abc' = BINARY 'ABC' AS is_match;
```
