# Day 3: Chapter 4 — Built-in Math and String Functions

In MySQL, **scalar functions** are built-in functions that take one or more inputs and return a **single** value as output. They are incredibly useful in `SELECT` lists, `WHERE` clauses, and `ORDER BY` statements.

---

## 🔢 1. Math and Numeric Functions

Here are the most commonly used mathematical scalar functions in SQL:

### A. ABS(x)
Returns the absolute (positive) value of a number.
*   **Real-time Use:** Calculating differences, financial balances, profit/loss variances.
```sql
SELECT ABS(-500); -- Output: 500
```

### B. DIV
Performs integer division, ignoring the remainder (floor division).
*   **Real-time Use:** Calculating group package counts, item packing.
```sql
SELECT 10 DIV 3; -- Output: 3
```

### C. MOD(a, b)
Returns the remainder of a division (modulo).
*   **Real-time Use:** Checking for even/odd IDs, round-robin cycles.
```sql
SELECT MOD(10, 3); -- Output: 1
```

### D. GREATEST(x1, x2, ...) & LEAST(x1, x2, ...)
Finds the largest or smallest value in a given list of columns or values.
*   **Real-time Use:** Finding max/min values across multiple columns in the same row.
```sql
SELECT GREATEST(10, 20, 30); -- Output: 30
SELECT LEAST(10, 20, 30);    -- Output: 10
```

### E. ROUND(x, d)
Rounds a number `x` to `d` decimal places. If `d` is omitted, it rounds to the nearest integer.
*   **Real-time Use:** Formatting currency, rounding grades.
```sql
SELECT ROUND(12.3456, 2); -- Output: 12.35
SELECT ROUND(4.6);        -- Output: 5
```

### F. TRUNCATE(x, d)
Chops off the decimal part after `d` decimal places **without rounding**.
*   **Real-time Use:** Financial systems where rounding up is not permitted.
```sql
SELECT TRUNCATE(12.3456, 2); -- Output: 12.34
```

### G. FLOOR(x) & CEIL(x) / CEILING(x)
*   **`FLOOR(x)`**: Rounds **down** to the next lowest integer.
*   **`CEIL(x)`**: Rounds **up** to the next highest integer.
```sql
SELECT FLOOR(4.7); -- Output: 4
SELECT CEIL(4.3);  -- Output: 5
```

### H. SQRT(x) & POW(x, y) / POWER(x, y)
*   **`SQRT(x)`**: Square root of a number.
*   **`POW(x, y)`**: Raises `x` to the power `y`.
```sql
SELECT SQRT(25);   -- Output: 5
SELECT POW(2, 3);  -- Output: 8
```

### I. RAND()
Generates a random floating-point number between `0` (inclusive) and `1` (exclusive).
*   **Real-time Use:** Random lottery draws, picking a random winner.
```sql
-- Select 1 random order from a table
SELECT * FROM Orders ORDER BY RAND() LIMIT 1;
```

### J. PI() & EXP(x)
*   **`PI()`**: Returns the value of $\pi$ (~3.141593).
*   **`EXP(x)`**: Returns $e^x$.
```sql
SELECT PI();    -- Output: 3.141593
SELECT EXP(1);  -- Output: 2.718282
```

## ⚙️ 2. Low-Level Bitwise Operators

Bitwise operators manipulate data at the binary level (bits: 0s and 1s). While rarely used in everyday business dashboards, they are common in high-performance networking, file systems, and hardware integrations.

| Operator | Description | Example | Binary Calculation | Output |
| :--- | :--- | :--- | :--- | :--- |
| **`&`** | Bitwise AND | `SELECT 5 & 3;` | `0101 & 0011 = 0001` | 1 |
| **`\|`** | Bitwise OR | `SELECT 5 \| 3;` | `0101 \| 0011 = 0111` | 7 |
| **`^`** | Bitwise XOR | `SELECT 5 ^ 3;` | `0101 ^ 0011 = 0110` | 6 |
| **`<<`** | Shift Left (Multiply by $2^n$) | `SELECT 5 << 1;` | Shift bits of `5` (0101) left by 1 | 10 |
| **`>>`** | Shift Right (Divide by $2^n$) | `SELECT 5 >> 1;` | Shift bits of `5` (0101) right by 1 | 2 |

## 🔤 3. String Functions (Restored & Completed)

String scalar functions allow you to transform, slice, and inspect text data in MySQL.

### A. CONCAT(str1, str2, ...) & CONCAT_WS(separator, str1, str2, ...)
*   **`CONCAT()`**: Merges multiple text strings together. If any input is `NULL`, the output is `NULL`.
    ```sql
    SELECT CONCAT('Raju', ' ', 'Sharma') AS full_name; -- Output: 'Raju Sharma'
    ```
*   **`CONCAT_WS()`**: (Concat With Separator). First argument is the separator, which joins the rest of the arguments.
    ```sql
    SELECT CONCAT_WS('-', '2026', '07', '25') AS date_str; -- Output: '2026-07-25'
    ```

### B. LENGTH(str) & CHAR_LENGTH(str)
*   **`LENGTH()`**: Returns the length of the string in **bytes**.
*   **`CHAR_LENGTH()`**: Returns the length of the string in **characters**.
    ```sql
    -- For standard ASCII strings, both are same:
    SELECT LENGTH('Cat'), CHAR_LENGTH('Cat'); -- Output: 3, 3
    ```

### C. UPPER(str) / UCASE(str) & LOWER(str) / LCASE(str)
Converts text cases.
```sql
SELECT UPPER('mysql'); -- Output: 'MYSQL'
SELECT LOWER('MYSQL'); -- Output: 'mysql'
```

### D. SUBSTRING(str, pos, len) / SUBSTR(str, pos, len)
Extracts a part of a string starting from position `pos` (1-indexed) for `len` characters. If `len` is omitted, it extracts to the end.
```sql
SELECT SUBSTRING('Database', 1, 4); -- Output: 'Data' (extracts 4 chars starting from index 1)
SELECT SUBSTRING('Database', 5);    -- Output: 'base'
```

### E. REPLACE(str, from_str, to_str)
Replaces all occurrences of `from_str` with `to_str` in a text.
```sql
SELECT REPLACE('I love SQL Server', 'SQL Server', 'MySQL'); -- Output: 'I love MySQL'
```

### F. TRIM(str) / LTRIM(str) / RTRIM(str)
Removes leading and trailing white spaces.
```sql
SELECT TRIM('  hello  '); -- Output: 'hello'
SELECT LTRIM('  hi');     -- Output: 'hi'
SELECT RTRIM('bye  ');    -- Output: 'bye'
```

### G. INSTR(str, substr)
Returns the position (1-indexed) of the first occurrence of a substring in a string. Returns `0` if not found.
```sql
SELECT INSTR('MySQL', 'SQL'); -- Output: 3
SELECT INSTR('MySQL', 'Java'); -- Output: 0
```

### H. LEFT(str, len) & RIGHT(str, len)
Slices a specified number of characters from the left or right of a string.
```sql
SELECT LEFT('Masterclass', 6);  -- Output: 'Master'
SELECT RIGHT('Masterclass', 5); -- Output: 'class'
```
