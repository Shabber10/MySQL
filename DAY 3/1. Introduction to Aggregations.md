# Day 3: Chapter 1 — Introduction to Aggregations

In SQL, **aggregation** refers to the process of summarizing multiple rows of data into a single, meaningful value. Instead of looking at individual transaction rows, aggregations allow us to answer high-level business questions like:
*   *"What is the total revenue?"*
*   *"How many orders were placed today?"*
*   *"What is the average rating of our products?"*

---

## 📊 The 5 Core Aggregate Functions

MySQL provides five main aggregate functions:

| Function | Description | Example |
| :--- | :--- | :--- |
| **`COUNT()`** | Returns the number of rows or non-null values. | `SELECT COUNT(*) FROM Sales;` |
| **`SUM()`** | Calculates the total sum of a numeric column. | `SELECT SUM(price) FROM Sales;` |
| **`AVG()`** | Calculates the average value of a numeric column. | `SELECT AVG(price) FROM Sales;` |
| **`MAX()`** | Finds the highest value in a column. | `SELECT MAX(price) FROM Sales;` |
| **`MIN()`** | Finds the lowest value in a column. | `SELECT MIN(price) FROM Sales;` |

---

## 🔍 Detailed Explanations and Syntax

### 1. `COUNT(expression)`
Counts the number of records returned by the query.
*   **`COUNT(*)`**: Counts every row in the table, including rows containing `NULL` values.
    ```sql
    -- Count the total number of orders/sales
    SELECT COUNT(*) AS total_orders FROM Sales;
    ```
*   **`COUNT(column_name)`**: Counts only the rows where the specified column is **not null**.
    ```sql
    -- Count rows that have marks defined (ignoring NULLs)
    SELECT COUNT(marks) AS active_students FROM students;
    ```
*   **`COUNT(DISTINCT column_name)`**: Counts the number of unique, non-null values.
    ```sql
    -- Find how many unique cities our sales came from
    SELECT COUNT(DISTINCT city) AS unique_cities FROM Sales;
    ```

### 2. `SUM(column)`
Adds up all the values in a numeric column.
*   It ignores `NULL` values.
*   If all values in the column are `NULL`, it returns `NULL`.
    ```sql
    -- Calculate the total quantity of items sold
    SELECT SUM(quantity) AS total_items_sold FROM Sales;
    ```

### 3. `AVG(column)`
Calculates the arithmetic mean (average) of all non-null values in a numeric column.
*   It ignores `NULL` values. (Note: Since it ignores nulls, it divides the sum by the count of *non-null* rows only).
    ```sql
    -- Calculate the average price of all sold products
    SELECT AVG(price) AS average_price FROM Sales;
    ```

### 4. `MAX(column)`
Returns the largest value in the column.
*   Works on numeric columns, date columns (returns the latest date), and character columns (returns the last string alphabetically).
*   Ignores `NULL` values.
    ```sql
    -- Find the highest product price
    SELECT MAX(price) AS highest_price FROM Sales;
    ```

### 5. `MIN(column)`
Returns the smallest value in the column.
*   Works on numeric columns, date columns (returns the earliest date), and character columns (returns the first string alphabetically).
*   Ignores `NULL` values.
    ```sql
    -- Find the lowest price among sales
    SELECT MIN(price) AS lowest_price FROM Sales;
    ```

---

## 💡 Key Takeaway for Students
Aggregate functions process a set of values to return a single value. When used by themselves, they collapse the entire result set into a single row. To analyze summaries across categories (e.g., total sales *per product*), we combine them with `GROUP BY` (which is covered in Chapter 2).
