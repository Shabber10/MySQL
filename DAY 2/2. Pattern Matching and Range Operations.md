# Day 2: Pattern Matching and Range Operations

In databases, you often need to search for values within a range, check if a value matches one of several options, or search for text that matches a specific pattern (like finding names starting with "J"). 

To do this, SQL provides three powerful keywords: `BETWEEN`, `IN`, and `LIKE`.

---

## 1. Range Filtering: `BETWEEN ... AND ...`

The `BETWEEN` operator filters values within a specific range. It is **inclusive**, meaning the start and end values are included in the results.

### Syntax:
```sql
SELECT columns FROM table 
WHERE column BETWEEN value1 AND value2;
```

### Examples:
```sql
-- Find employees earning between $50,000 and $80,000 (inclusive)
SELECT first_name, salary FROM employees
WHERE salary BETWEEN 50000.00 AND 80000.00;

-- Find employees hired between January 1, 2025 and December 31, 2025
SELECT first_name, join_date FROM employees
WHERE join_date BETWEEN '2025-01-01' AND '2025-12-31';
```

---

## 2. Set Filtering: `IN (...)`

The `IN` operator allows you to specify multiple values in a `WHERE` clause. It acts as a shortcut for writing multiple `OR` conditions.

### Examples:
```sql
-- The long way (using OR):
SELECT first_name, department FROM employees
WHERE department = 'IT' OR department = 'HR' OR department = 'Finance';

-- The short way (using IN):
SELECT first_name, department FROM employees
WHERE department IN ('IT', 'HR', 'Finance');
```

You can also combine `IN` with `NOT` to select values *outside* the list:
```sql
-- Find employees who do NOT work in IT, HR, or Finance
SELECT first_name, department FROM employees
WHERE department NOT IN ('IT', 'HR', 'Finance');
```

---

## 3. Pattern Matching: `LIKE` and Wildcards

When searching text columns for partial matches, we use the `LIKE` operator combined with **Wildcards**.

| Wildcard | Description | Example |
| :---: | :--- | :--- |
| **`%`** | Represents **zero, one, or multiple** characters. | `LIKE 'J%'` (starts with J) |
| **`_`** | Represents **exactly one** character. | `LIKE 'J_n'` (3-letter word starting with J, ending with n) |

### Common Wildcard Patterns:
*   `LIKE 'A%'`: Matches values starting with "A" (e.g., *Alice*, *Albert*).
*   `LIKE '%son'`: Matches values ending with "son" (e.g., *Jackson*, *Wilson*).
*   `LIKE '%or%'`: Matches values containing "or" anywhere (e.g., *Jordan*, *Taylor*, *George*).
*   `LIKE '_a%'`: Matches values where "a" is the second character (e.g., *Ravi*, *Jane*, *Mary*).
*   `LIKE 'J__n'`: Matches values starting with "J", followed by exactly two characters, ending with "n" (e.g., *John*, *Joan*).

```sql
-- Find employees whose names start with 'A'
SELECT first_name FROM employees
WHERE first_name LIKE 'A%';

-- Find employees with a 5-letter department code starting with 'Sales'
SELECT first_name, department FROM employees
WHERE department LIKE 'Sales%';
```

> [!NOTE]
> By default in MySQL, character comparisons are **case-insensitive** (e.g., `LIKE 'j%'` will match *John* and *jane*). If you need a case-sensitive match, you can cast the column using the `BINARY` keyword: `WHERE BINARY first_name LIKE 'J%'`.
