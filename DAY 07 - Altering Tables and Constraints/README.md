# DAY 07: Altering Tables & Constraints

This directory contains the curriculum, practice exercises, and scripts for **Altering Tables & Constraints**.

## 📚 Chapters & Content Outline

*   **[1. Modifying Tables with ALTER TABLE](1.%20Modifying%20Tables%20with%20ALTER%20TABLE.md)** - Master structural schema changes. Learn how to add, drop, modify, and rename columns, and rename tables while managing data truncation risks.
*   **[2. Managing Table Constraints](2.%20Managing%20Table%20Constraints.md)** - Learn to manage table constraints after creation. Study how to add and drop Primary Keys, Foreign Keys, Unique constraints, and CHECK constraints.
*   **[3. Day 7 Hands-on Practice and Exercises](3.%20Day%207%20Hands-on%20Practice%20and%20Exercises.md)** - Practice transforming a legacy unconstrained table by modifying columns and applying constraints progressively.
*   **[day7_practice_script.sql](day7_practice_script.sql)** - Executable SQL practice script implementing all columns modifications and constraints alterations.
