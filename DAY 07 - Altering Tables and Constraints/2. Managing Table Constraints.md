# Day 07: Chapter 2 — Managing Table Constraints

Constraints enforce rules on your data. While they are usually defined during `CREATE TABLE`, you often need to add, alter, or remove constraints on existing tables. 

---

## 1. Adding Constraints

To apply integrity constraints to existing tables, combine `ALTER TABLE` with the `ADD` keyword.

### A. Adding Primary Key
A table can only have one primary key. The column(s) must already be defined as `NOT NULL`.
```sql
ALTER TABLE Employees
ADD PRIMARY KEY (emp_id);
```

### B. Adding Unique Constraints
Ensures a secondary column does not store duplicate values.
```sql
ALTER TABLE Employees
ADD UNIQUE (email);
```

### C. Adding Check Constraints (MySQL 8.0+)
Enforces a condition that all records must satisfy before being committed.
```sql
ALTER TABLE Employees
ADD CONSTRAINT chk_salary CHECK (salary >= 0);
```

### D. Adding Foreign Keys
Links a column in the child table to a primary key in the parent table.
```sql
ALTER TABLE Employees
ADD CONSTRAINT fk_emp_dept
FOREIGN KEY (dept_id) REFERENCES Departments(dept_id)
ON DELETE SET NULL;
```

---

## 🏷️ The Importance of Naming Constraints

If you do not explicitly assign a name to a constraint (using `CONSTRAINT name`), MySQL will automatically generate one for you (such as `employees_ibfk_1` or `email_2`). 

### Why you should always write named constraints:
1.  **Debugging**: Error messages display the constraint name (e.g., `Constraint 'chk_salary' failed`). A named constraint tells you exactly what went wrong.
2.  **Dropping**: To remove a constraint later, you must know its exact name. Searching for auto-generated database names is tedious.

---

## 2. Dropping Constraints

To remove a rule, you must reference its identifier. The syntax differs depending on the constraint type:

### A. Dropping Primary Key
Since there is only one Primary Key, you do not need to name it:
```sql
ALTER TABLE Employees
DROP PRIMARY KEY;
```
*(Warning: You cannot drop a Primary Key if it is referenced by a Foreign Key in another table, or if it is defined as an `AUTO_INCREMENT` column).*

### B. Dropping Foreign Keys
To remove a relational link, specify the Foreign Key constraint name:
```sql
ALTER TABLE Employees
DROP FOREIGN KEY fk_emp_dept;
```

### C. Dropping Unique Constraints (Indexes)
In MySQL, Unique constraints are implemented underneath as **Unique Indexes**. Therefore, to drop a Unique constraint, you must drop its index:
```sql
ALTER TABLE Employees
DROP INDEX email;
```

### D. Dropping Check Constraints
To remove a Check constraint, specify its constraint name:
```sql
ALTER TABLE Employees
DROP CONSTRAINT chk_salary;
```
