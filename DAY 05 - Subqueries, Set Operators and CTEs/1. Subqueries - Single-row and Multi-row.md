# Day 05: Chapter 1 — Subqueries (Single-row & Multi-row)

A **subquery** (or nested query) is a query query nested inside another SQL statement. The statement containing the subquery is called the **outer query** (or main query), and the nested query is called the **inner query** (or subquery).

Subqueries allow you to perform dynamic, multi-step queries where the output of one query determines the search condition of another.

---

## 🔄 How Subqueries Execute

In most cases, the inner subquery executes **first** (once), returns its result set to the outer query, and then the outer query uses that result to filter or compute its own rows.

```
       ┌────────────────────────────────────────────────────────┐
       │   OUTER QUERY (Main query)                             │
       │   SELECT emp_name FROM Employees                       │
       │   WHERE salary > (                                     │
       │       ┌────────────────────────────────────────────┐   │
       │       │   INNER SUBQUERY                           │   │
       │       │   SELECT AVG(salary) FROM Employees        │   │
       │       └────────────────────────────────────────────┘   │
       │   );                                                   │
       └────────────────────────────────────────────────────────┘
```

## 1️⃣ Single-row Subqueries

A **single-row subquery** is an inner query that returns **exactly one row and one column** (a scalar value). 

### Comparison Operators
Because the subquery returns a single value, you use standard comparison operators in the outer query:
`=`, `>`, `<`, `>=`, `<=`, `<>` (or `!=`)

### Examples

#### Example 1: Find the employee who earns the maximum salary.
We first find the maximum salary, and then find the employee matching that salary.
```sql
SELECT emp_name, salary
FROM Employees
WHERE salary = (SELECT MAX(salary) FROM Employees);
```
*   **Inner query returns:** `35000`
*   **Outer query resolves to:** `WHERE salary = 35000`
*   **Result:** David (35000)

#### Example 2: Find employees who earn more than Alice.
First find Alice's salary, then filter for salaries greater than that.
```sql
SELECT emp_name, salary
FROM Employees
WHERE salary > (SELECT salary FROM Employees WHERE emp_name = 'Alice');
```
*   **Inner query returns:** `12000`
*   **Outer query resolves to:** `WHERE salary > 12000`
*   **Result:** Bob (20000), David (35000), Emma (25000), Raj (15000)

#### Example 3: Find employees who earn more than the average salary.
First calculate average salary, then filter.
```sql
SELECT emp_name, salary
FROM Employees
WHERE salary > (SELECT AVG(salary) FROM Employees);
```
*   **Inner query returns:** `18666.67` (average of all salaries)
*   **Outer query resolves to:** `WHERE salary > 18666.67`
*   **Result:** Bob (20000), David (35000), Emma (25000)

## 2️⃣ Multi-row Subqueries

A **multi-row subquery** returns **multiple rows but a single column**. Because it returns a list of values, using standard comparison operators (like `=`) will cause an error:
`ERROR 1242 (21000): Subquery returns more than 1 row`

To compare a column against multiple rows, you must use special operators: `IN`, `ANY` (or `SOME`), and `ALL`.

### A. The `IN` Operator
Returns rows in the outer query that match **any** value returned by the subquery (acts like a list operator).

#### Example: Find employees working in the same department as Bob.
First, find Bob's department(s), then match other employees in those departments.
```sql
SELECT emp_name, dept
FROM Employees
WHERE dept IN (SELECT dept FROM Employees WHERE emp_name = 'Bob');
```
*   **Inner query returns:** `IT`
*   **Outer query resolves to:** `WHERE dept IN ('IT')`
*   **Result:** Alice (IT), Bob (IT)

---

### B. The `ANY` (or `SOME`) Operator
Compares a value from the outer query to **each** value returned by the subquery.
*   `> ANY (list)`: Greater than the **minimum** value in the list.
*   `< ANY (list)`: Less than the **maximum** value in the list.
*   `= ANY (list)`: Equivalent to `IN`.

#### Example: Find employees who earn more than ANY employee in the HR department.
Find employees whose salary is greater than *at least one* person in HR. This is equivalent to being greater than the *lowest paid* HR employee.
```sql
SELECT emp_name, salary, dept
FROM Employees
WHERE salary > ANY (SELECT salary FROM Employees WHERE dept = 'HR');
```
*   **Inner query returns:** `5000`, `15000` (salaries in HR)
*   **Outer query resolves to:** `WHERE salary > 5000` (since 5000 is the minimum)
*   **Result:** Alice (12000), Bob (20000), David (35000), Emma (25000), Raj (15000)

---

### C. The `ALL` Operator
Compares a value from the outer query to **all** values returned by the subquery.
*   `> ALL (list)`: Greater than the **maximum** value in the list.
*   `< ALL (list)`: Less than the **minimum** value in the list.

#### Example: Find employees who earn more than ALL employees in the HR department.
Find employees whose salary is greater than *everyone* in HR (i.e. greater than the highest salary in HR).
```sql
SELECT emp_name, salary, dept
FROM Employees
WHERE salary > ALL (SELECT salary FROM Employees WHERE dept = 'HR');
```
*   **Inner query returns:** `5000`, `15000` (salaries in HR)
*   **Outer query resolves to:** `WHERE salary > 15000` (since 15000 is the maximum)
*   **Result:** Bob (20000), David (35000), Emma (25000)

---

## 🔑 Key Commonalities & Differences

| Operator | Comparison Logic | Practical Rule of Thumb |
| :--- | :--- | :--- |
| **`IN`** | Matches any item in the subquery list. | Check if a value belongs to a dynamic set. |
| **`> ANY`** | Greater than *at least one* value. | Must be greater than the **minimum** value of the list. |
| **`< ANY`** | Less than *at least one* value. | Must be less than the **maximum** value of the list. |
| **`> ALL`** | Greater than *every* value in the list. | Must be greater than the **maximum** value of the list. |
| **`< ALL`** | Less than *every* value in the list. | Must be less than the **minimum** value of the list. |
