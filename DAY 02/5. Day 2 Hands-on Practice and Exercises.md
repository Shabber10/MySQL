# Day 02: Hands-on Practice and Exercises

This guide walks you through a complete, step-by-step practical session: **Building and Querying an HR Employee Database**. 

We will apply all the Day 02 concepts—logical combinations, patterns, range searches, null checks, sorting, and row limits.

---

## The Scenario
You are tasked with querying the employee records database for a growing tech startup. You need to answer several business questions (e.g., finding underpaid staff, matching names, locating missing emails, and listing top earners).

---

## Step 1: Database Setup

First, open your MySQL Command Line or GUI database manager and execute these setup commands:

```sql
-- Create and select a practice database
CREATE DATABASE company_db;
USE company_db;

-- Create the employees table
CREATE TABLE employees (
    employee_id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    department VARCHAR(50),
    salary DECIMAL(10, 2),
    email VARCHAR(100),
    join_date DATE
);
```

## Step 2: Advanced Queries (Apply Day 02 Concepts)

Run these queries to verify your understanding:

### 1. Complex Logic (IT or Sales making over $65k)
```sql
SELECT first_name, department, salary 
FROM employees
WHERE (department = 'IT' OR department = 'Sales') AND salary > 65000.00;
```

### 2. Range Operations (Salary between $50k and $70k)
```sql
SELECT first_name, department, salary 
FROM employees
WHERE salary BETWEEN 50000.00 AND 70000.00;
```

### 3. List Match (Finance or Marketing departments)
```sql
SELECT first_name, department 
FROM employees
WHERE department IN ('Finance', 'Marketing');
```

### 4. Text Searches (First name ending in 'y' or starting with 'A')
```sql
SELECT first_name FROM employees
WHERE first_name LIKE 'A%' OR first_name LIKE '%y';
```

### 5. Check for Missing Emails
```sql
SELECT first_name, last_name, email 
FROM employees
WHERE email IS NULL;
```

### 6. Get Top 3 Highest Earners
```sql
SELECT first_name, department, salary 
FROM employees
ORDER BY salary DESC
LIMIT 3;
```

## Step 3: Day 02 Practice Exercises

Try to write queries for these questions yourself before looking at the answers!

### Questions:
1.  Find all employees who do **NOT** work in IT or Sales.
2.  Find all employees who were hired in the year **2025**.
3.  Find all employees whose last name has `i` as the second letter.
4.  Find the employee with the lowest salary (order and limit).

---

### Answers:

#### 1. Not in IT or Sales:
```sql
SELECT first_name, department FROM employees
WHERE department NOT IN ('IT', 'Sales');
```

#### 2. Hired in 2025:
```sql
SELECT first_name, join_date FROM employees
WHERE join_date BETWEEN '2025-01-01' AND '2025-12-31';
```

#### 3. Last name has 'i' as second letter:
```sql
SELECT first_name, last_name FROM employees
WHERE last_name LIKE '_i%';
```

#### 4. Lowest salary:
```sql
SELECT first_name, salary FROM employees
ORDER BY salary ASC
LIMIT 1;
```

## Step 4: Practice Scenario 2 — Logical Negation (NOT Operators)

We will use the following `students` table to practice logical negation operators:

```sql
CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    marks INT,
    city VARCHAR(50)
);

INSERT INTO students VALUES
(1, 'Amit', 18, 85, 'Delhi'),
(2, 'Sara', 19, 72, 'Mumbai'),
(3, 'John', 18, 90, 'Delhi'),
(4, 'Ravi', 20, 60, 'Chennai'),
(5, 'Meena', 21, 50, 'Hyderabad');
```

### Questions, Queries, and Expected Outputs:

#### Q1. Display students who are NOT from Delhi.
*   **Query:**
    ```sql
    SELECT name, city FROM students WHERE NOT city = 'Delhi';
    ```
*   **Expected Output:**
    | name | city |
    | :--- | :--- |
    | Sara | Mumbai |
    | Ravi | Chennai |
    | Meena | Hyderabad |

#### Q2. Display students who are NOT in Delhi and Mumbai.
*   **Query:**
    ```sql
    SELECT name, city FROM students WHERE city NOT IN ('Delhi', 'Mumbai');
    ```
*   **Expected Output:**
    | name | city |
    | :--- | :--- |
    | Ravi | Chennai |
    | Meena | Hyderabad |

#### Q3. Display students whose names DO NOT start with 'A'.
*   **Query:**
    ```sql
    SELECT name FROM students WHERE name NOT LIKE 'A%';
    ```
*   **Expected Output:**
    | name |
    | :--- |
    | Sara |
    | John |
    | Ravi |
    | Meena |

#### Q4. Display students whose names DO NOT end with 'a'.

*   **Expected Output:**

    | Amit |

#### Q5. Display students whose marks are NOT greater than 70.
