# Day 13: Hands-on Practice & Exercises

This module contains practical exercises to analyze query performance, interpret `EXPLAIN` execution plans, and optimize slow queries in MySQL.

---

## 📋 Exercise Overview

1. **Exercise 1:** Identify a Full Table Scan (`type: ALL`) using `EXPLAIN`.
2. **Exercise 2:** Fix a function-wrapped column query (`YEAR(order_date)`) by converting it to an indexable range query.
3. **Exercise 3:** Eliminate `Using filesort` by creating a composite index for `WHERE` + `ORDER BY`.
4. **Exercise 4:** Create a Covering Index to achieve `Using index` in `Extra`.
5. **Exercise 5:** Run microsecond performance comparison using `EXPLAIN ANALYZE`.

---

## 🛠️ Solutions & Execution Guide

Refer to `day13_practice_script.sql` in this folder for the full executable script.

```sql
-- Compare unoptimized vs optimized query execution plans:
EXPLAIN SELECT * FROM Orders WHERE YEAR(order_date) = 2026;
EXPLAIN SELECT * FROM Orders WHERE order_date >= '2026-01-01' AND order_date <= '2026-12-31';
```
