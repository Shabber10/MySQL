# Day 13: Chapter 1 — Query Performance Analysis

Query performance tuning is the art and science of optimizing database queries to execute in minimal time using minimal CPU, memory, and disk I/O resources.

---

## ⚡ 1. Primary Causes of Slow Queries

Slow database performance is usually driven by one or more of the following issues:

1. ❌ **Full Table Scans (`ALL`):** MySQL reads every single row in a table because appropriate indexes are missing.
2. ❌ **Fetching Excess Data:** Using `SELECT *` instead of retrieving only required columns.
3. ❌ **Functions on Indexed Columns:** Writing `WHERE YEAR(created_at) = 2026` invalidates the index on `created_at`.
4. ❌ **Unindexed Join Columns:** Joining large tables without foreign key / join column indexes.
5. ❌ **Implicit Data Type Conversions:** Comparing a string column against an integer value.

---

## 📊 2. Query Profiling in MySQL

MySQL Profiling measures the precise time spent in each phase of query execution (e.g. sending data, locking, opening tables).

### How to use Query Profiling:

```sql
-- 1. Enable profiling for the current session
SET profiling = 1;

-- 2. Run your queries
SELECT * FROM Employees WHERE department = 'IT';
SELECT COUNT(*) FROM Orders WHERE total_amount > 5000;

-- 3. Show list of recent profiled queries
SHOW PROFILES;

-- 4. Get detailed CPU & execution breakdown for a specific Query ID
SHOW PROFILE FOR QUERY 1;
SHOW PROFILE CPU FOR QUERY 1;
```

---

## 🐢 3. The Slow Query Log

The **Slow Query Log** records all SQL statements that take longer than a specified threshold (`long_query_time`) to execute.

### Configuring Slow Query Logging:

```sql
-- Check current slow query log status
SHOW VARIABLES LIKE 'slow_query_log%';
SHOW VARIABLES LIKE 'long_query_time';

-- Turn on slow query logging
SET GLOBAL slow_query_log = 'ON';

-- Set threshold to 2 seconds
SET GLOBAL long_query_time = 2;
```

System administrators use command-line utilities like `mysqldumpslow` to parse and aggregate slow logs to find top performance bottlenecks.
