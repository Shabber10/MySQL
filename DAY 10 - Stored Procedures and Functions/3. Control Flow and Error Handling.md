# Day 10: Chapter 3 — Control Flow & Error Handling

To build complex business logic inside Stored Procedures and Functions, MySQL provides procedural **Control Flow statements** (`IF-ELSE`, `CASE`, `WHILE`, `LOOP`) and **Handler Error Handling** constructs.

---

## 1. Conditional Logic

### A. `IF ... THEN ... ELSEIF ... ELSE` Statement

Evaluates boolean conditions sequentially and executes the matching block.

```sql
DELIMITER //

CREATE PROCEDURE ClassifyStudent(IN p_marks INT, OUT p_grade VARCHAR(20))
BEGIN
    IF p_marks >= 90 THEN
        SET p_grade = 'Distinction';
    ELSEIF p_marks >= 75 THEN
        SET p_grade = 'First Class';
    ELSEIF p_marks >= 40 THEN
        SET p_grade = 'Pass';
    ELSE
        SET p_grade = 'Fail';
    END IF;
END //

DELIMITER ;

-- Calling procedure:
CALL ClassifyStudent(82, @grade);
SELECT @grade AS student_result; -- Output: 'First Class'
```

---

### B. `CASE` Statement

Useful when matching a variable against multiple explicit values or conditions.

```sql
DELIMITER //

CREATE PROCEDURE GetShippingDelay(IN p_shipping_mode VARCHAR(20), OUT p_days INT)
BEGIN
    CASE p_shipping_mode
        WHEN 'Express' THEN SET p_days = 1;
        WHEN 'Standard' THEN SET p_days = 3;
        WHEN 'Economy' THEN SET p_days = 7;
        ELSE SET p_days = 14;
    END CASE;
END //

DELIMITER ;
```

## 2. Iterative Loops

MySQL supports three types of loops inside stored procedures:

### A. `WHILE` Loop
Executes as long as the condition remains `TRUE` (tests condition **before** entering loop).

```sql
DELIMITER //

CREATE PROCEDURE InsertNumbersWhile(IN max_count INT)
BEGIN
    DECLARE counter INT DEFAULT 1;
    
    WHILE counter <= max_count DO
        INSERT INTO AuditLog (log_message) VALUES (CONCAT('Iteration #', counter));
        SET counter = counter + 1;
    END WHILE;
END //

DELIMITER ;
```

---

### B. `REPEAT ... UNTIL` Loop
Executes at least once and continues until the condition becomes `TRUE` (tests condition **after** executing loop body).

```sql
DELIMITER //

CREATE PROCEDURE InsertNumbersRepeat(IN max_count INT)
BEGIN
    DECLARE counter INT DEFAULT 1;
    
    REPEAT
        INSERT INTO AuditLog (log_message) VALUES (CONCAT('Repeat #', counter));
        SET counter = counter + 1;
    UNTIL counter > max_count
    END REPEAT;
END //

DELIMITER ;
```

---

### C. `LOOP` with `LEAVE` & `ITERATE`
A flexible loop controlled by label names:
* `LEAVE label_name`: Immediately exits the loop (like `break`).
* `ITERATE label_name`: Skips the rest of the current iteration and restarts loop (like `continue`).

```sql
DELIMITER //

CREATE PROCEDURE ProcessEvenNumbers(IN max_val INT)
BEGIN
    DECLARE counter INT DEFAULT 0;
    
    my_loop: LOOP
        SET counter = counter + 1;
        
        IF counter > max_val THEN
            LEAVE my_loop; -- Exit loop
        END IF;
        
        IF MOD(counter, 2) <> 0 THEN
            ITERATE my_loop; -- Skip odd numbers
        END IF;
        
        INSERT INTO AuditLog (log_message) VALUES (CONCAT('Even Number: ', counter));
    END LOOP my_loop;
END //

DELIMITER ;
```

## 3. Exception & Error Handling (`DECLARE HANDLER`)

When an SQL error occurs inside a procedure (such as duplicate primary key insertion, foreign key constraint failure, or missing table), MySQL aborts execution by default. 

Using **Error Handlers**, you can intercept errors, gracefully roll back transactions, or record custom error logs.

### Syntax
```sql
DECLARE {CONTINUE | EXIT} HANDLER FOR {error_code | SQLEXCEPTION | NOT FOUND}
BEGIN
    -- Action to take when error occurs
END;
```
* **`CONTINUE`**: Executes error action and continues running the rest of the procedure.
* **`EXIT`**: Executes error action and terminates procedure execution immediately.

### Example: Transaction Safe Insert with Error Exit Handler

```sql
DELIMITER //

CREATE PROCEDURE SafeAddCustomer(
    IN p_id INT, 
    IN p_name VARCHAR(50), 
    IN p_email VARCHAR(50),
    OUT p_status VARCHAR(100)
)
BEGIN
    -- Declare Exit Handler for Duplicate PK / SQL Errors
    DECLARE EXIT HANDLER FOR SQLEXCEPTION
    BEGIN
        ROLLBACK;
        SET p_status = 'ERROR: Insertion failed. Transaction rolled back.';
    END;

    START TRANSACTION;
    
    INSERT INTO Customers (customer_id, name, email) 
    VALUES (p_id, p_name, p_email);
    
    COMMIT;
    SET p_status = 'SUCCESS: Customer inserted successfully.';
END //

DELIMITER ;
```
