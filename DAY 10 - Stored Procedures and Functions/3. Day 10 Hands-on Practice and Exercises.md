# Day 10: Hands-on Practice & Exercises

This module contains practical exercises to build, test, and debug Stored Procedures, User-Defined Functions (UDFs), and Error Handlers in MySQL.

---

## 📋 Exercise Overview

1. **Exercise 1:** Create an `IN` parameter procedure to retrieve high-performing employees.
2. **Exercise 2:** Create an `OUT` parameter procedure to calculate department total payroll.
3. **Exercise 3:** Create an `INOUT` parameter procedure to apply annual performance bonuses.
4. **Exercise 4:** Create a User-Defined Function (UDF) `CalculateAge` to compute a person's age from birthdate.
5. **Exercise 5:** Create an `IF-ELSE` procedure to classify product price ranges.
6. **Exercise 6:** Create a `WHILE` loop procedure to insert batch test logs into an audit table.
7. **Exercise 7:** Create a transaction-safe procedure with `DECLARE EXIT HANDLER FOR SQLEXCEPTION`.

---
