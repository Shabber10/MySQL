## 🟢 Part 1: Stored Procedure Exercises

### Exercise 1: Get Employees by Department
Create a stored procedure named `GetEmpByDept` that accepts a department name (`IN p_dept VARCHAR(50)`) and returns all employees working in that department.

*   **Query:**
    ```sql
    DELIMITER //
    CREATE PROCEDURE GetEmpByDept(IN p_dept VARCHAR(50))
    BEGIN
        SELECT * FROM Employees WHERE department = p_dept;
    END //
    DELIMITER ;

    -- Test:
    CALL GetEmpByDept('IT');
    ```

### Exercise 2: Add New Employee Procedure
Create a stored procedure `AddEmployee` that inserts a new employee and returns a confirmation message.

*   **Query:**
    ```sql
    DELIMITER //
    CREATE PROCEDURE AddEmployee(
        IN p_name VARCHAR(50),
        IN p_dept VARCHAR(50),
        IN p_salary DECIMAL(10,2),
        IN p_city VARCHAR(50)
    )
    BEGIN
        INSERT INTO Employees (name, department, salary, city)
        VALUES (p_name, p_dept, p_salary, p_city);
        SELECT 'New Employee Added Successfully!' AS status;
    END //
    DELIMITER ;

    -- Test:
    CALL AddEmployee('Vikram', 'Finance', 60000.00, 'Mumbai');
    ```

### Exercise 3: Calculate Average Salary by Department (`OUT` Parameter)
Create a stored procedure `GetAvgSalary` that takes a department name and returns the average salary in an `OUT` parameter.

*   **Query:**
    ```sql
    DELIMITER //
    CREATE PROCEDURE GetAvgSalary(
        IN p_dept VARCHAR(50),
        OUT p_avg DECIMAL(10,2)
    )
    BEGIN
        SELECT AVG(salary) INTO p_avg
        FROM Employees
        WHERE department = p_dept;
    END //
    DELIMITER ;

    -- Test:
    CALL GetAvgSalary('IT', @it_avg);
    SELECT @it_avg AS Average_IT_Salary;
    ```

## 🟡 Part 2: Stored Function Exercises

### Exercise 4: Calculate Annual Salary Function
Create a stored function `GetAnnualSalary` that takes a monthly salary and returns the annual salary (monthly * 12).

*   **Query:**
    ```sql
    DELIMITER //
    CREATE FUNCTION GetAnnualSalary(monthly_sal DECIMAL(10,2))
    RETURNS DECIMAL(10,2)
    DETERMINISTIC
    BEGIN
        RETURN monthly_sal * 12;
    END //
    DELIMITER ;

    -- Test:
    SELECT name, salary, GetAnnualSalary(salary) AS annual_salary FROM Employees;
    ```
