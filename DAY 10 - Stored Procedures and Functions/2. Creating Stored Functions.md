# Day 10: Chapter 2 — Creating Stored Functions

A **Stored Function** (User-Defined Function or UDF) is a database object that takes zero or more input parameters, performs calculations or data lookups, and **returns a single scalar value**.

Unlike stored procedures, stored functions can be called directly within SQL expressions (such as `SELECT`, `WHERE`, `HAVING`, and `ORDER BY`).

---

## 🆚 1. Stored Procedure vs. Stored Function

| Feature | Stored Procedure ⚙️ | Stored Function 🧮 |
| :--- | :--- | :--- |
| **Return Value** | May return zero, one, or multiple result sets | Must return **exactly one scalar value** via `RETURN` |
| **Invocation** | Called independently with `CALL procedure_name()` | Called directly within SQL statements (e.g. `SELECT fn()`) |
| **Parameters** | Accepts `IN`, `OUT`, and `INOUT` parameters | Accepts only **input parameters** (default `IN`) |
| **DML Statements**| Can freely perform `INSERT`, `UPDATE`, `DELETE` | Used primarily for calculations; DML side-effects are discouraged |
| **Usage Context** | Used to execute workflow steps | Used in expressions like `SELECT col, calculate_tax(col) FROM tbl` |

---

## 🛠️ 2. Creating a Stored Function

### Syntax:
```sql
DELIMITER //

CREATE FUNCTION function_name(param1 data_type, param2 data_type)
RETURNS return_data_type
DETERMINISTIC
BEGIN
    -- Declaration of local variables
    DECLARE result return_data_type;
    
    -- Function logic
    SET result = param1 + param2;
    
    -- Must return a single value
    RETURN result;
END //

DELIMITER ;
```

### Deterministic Characteristics:
MySQL requires you to specify the function's deterministic nature:
*   **`DETERMINISTIC`**: The function always produces the exact same output for the same input parameters (e.g., mathematical formulas, string formatting).
*   **`NOT DETERMINISTIC`**: The function can produce different outputs for the same inputs (e.g., using `NOW()`, `RAND()`, or reading dynamic table rows).
*   **`READS SQL DATA`**: Indicates the function only reads data from tables (`SELECT`).
*   **`NO SQL`**: Indicates the function contains no SQL statements.

## 💻 3. Practical Examples

### Example 1: Calculate Tax Amount
```sql
DELIMITER //

CREATE FUNCTION CalculateTax(salary DECIMAL(10,2))
RETURNS DECIMAL(10,2)
DETERMINISTIC
BEGIN
    DECLARE tax DECIMAL(10,2);
    IF salary > 50000 THEN
        SET tax = salary * 0.20; -- 20% tax
    ELSE
        SET tax = salary * 0.10; -- 10% tax
    END IF;
    RETURN tax;
END //

DELIMITER ;

-- Calling the function in a SELECT query:
SELECT name, salary, CalculateTax(salary) AS tax_amount FROM emp;
```

### Example 2: Format Full Name
```sql
DELIMITER //

CREATE FUNCTION FormatFullName(first_name VARCHAR(30), last_name VARCHAR(30))
RETURNS VARCHAR(65)
DETERMINISTIC
BEGIN
    RETURN CONCAT(UPPER(LEFT(first_name, 1)), LOWER(SUBSTRING(first_name, 2)), ' ', UPPER(last_name));
END //

DELIMITER ;

-- Calling the function:
SELECT FormatFullName('john', 'DOE') AS formatted_name;
-- Output: 'John DOE'
```

## 🗑️ 4. Managing Functions

### Drop a Function:
```sql
DROP FUNCTION IF EXISTS CalculateTax;
```

### Show Function Status / Definition:
```sql
SHOW FUNCTION STATUS WHERE Db = 'day10_practice';
SHOW CREATE FUNCTION CalculateTax;
```
