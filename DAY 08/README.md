# DAY 08: Transactions & Concurrency

This directory contains the curriculum, practice exercises, and scripts for **Transactions & Concurrency**.

---

## 📚 Chapters & Content Outline

*   **[1. ACID Properties and Transactions](1.%20ACID%20Properties%20and%20Transactions.md)** - Learn the concept of database transactions and explore the foundational ACID properties (Atomicity, Consistency, Isolation, Durability) with a banking transfer scenario.
*   **[2. Transaction Control - COMMIT and ROLLBACK](2.%20Transaction%20Control%20-%20COMMIT%20and%20ROLLBACK.md)** - Master transaction commands. Study `START TRANSACTION`, `COMMIT`, `ROLLBACK`, and manage granular nested changes using `SAVEPOINT` configurations.
*   **[3. Concurrency and Isolation Levels](3.%20Concurrency%20and%20Isolation%20Levels.md)** - Understand database concurrency. Study the three read phenomena (Dirty, Non-repeatable, and Phantom Reads) and learn to set ANSI isolation levels and locks in MySQL.
*   **[4. Day 8 Hands-on Practice and Exercises](4.%20Day%208%20Hands-on%20Practice%20and%20Exercises.md)** - Run hands-on tasks simulating transaction rollbacks, savepoints, and concurrent terminal executions to witness locks and isolation levels.
*   **[day8_practice_script.sql](day8_practice_script.sql)** - Executable SQL practice script demonstrating commits, rollbacks, savepoints, and row locking operations.
