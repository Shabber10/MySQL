# Day 02: Sorting and Restricting Results

By default, MySQL returns rows in the order they were inserted into the table. To display results in a structured, alphabetical, or numerical order, we use the `ORDER BY` clause. To limit the size of the results (e.g., pagination or showing only the top records), we use `LIMIT`.

---

## 1. Sorting Results: `ORDER BY`

The `ORDER BY` clause is used to sort the result set in ascending or descending order.

### Syntax:
```sql
SELECT columns FROM table
ORDER BY column_name [ASC | DESC];
```
*   `ASC`: Sorts in ascending order (default: smallest to largest, A to Z, oldest date to newest).
*   `DESC`: Sorts in descending order (largest to smallest, Z to A, newest date to oldest).

### Examples:
```sql
-- Sort employees alphabetically by their last name (A to Z)
SELECT first_name, last_name FROM employees
ORDER BY last_name ASC;

-- Sort employees by salary, highest first (largest to smallest)
SELECT first_name, salary FROM employees
ORDER BY salary DESC;
```

### Sorting by Multiple Columns:
You can sort by more than one column. MySQL will sort by the first column, and if there are duplicate values, it will sort those duplicates by the second column.
```sql
-- Sort by department (alphabetical), then by salary (highest first) within each department
SELECT first_name, department, salary FROM employees
ORDER BY department ASC, salary DESC;
```

---

## 2. Restricting Results: `LIMIT`

The `LIMIT` clause restricts the number of rows returned by the query. This is extremely useful for performance, preventing massive data downloads, or for displaying web page results in chunks (pagination).

### Syntax:
```sql
SELECT columns FROM table
LIMIT number_of_rows;
```

### Examples:
```sql
-- Get only the first 5 rows of the employees table
SELECT * FROM employees
LIMIT 5;
```

### Combining `ORDER BY` and `LIMIT` (Top-N Queries):
To find the highest or lowest values, sort the data first, and then apply a limit.

```sql
-- Find the top 3 highest paid employees
SELECT first_name, salary FROM employees
ORDER BY salary DESC
LIMIT 3;

### Pagination with `LIMIT` and `OFFSET`:
When displaying query results on a website (e.g. 10 items per page), you need to skip the first $N$ rows and fetch the next chunk.

#### Syntax Options:
*   `LIMIT row_count OFFSET offset_value;`
*   `LIMIT offset_value, row_count;`

```sql
-- Page 1: Fetch rows 1 to 10 (offset 0)
SELECT * FROM employees ORDER BY employee_id LIMIT 10 OFFSET 0;

-- Page 2: Skip first 10 rows, fetch next 10 rows (offset 10)
SELECT * FROM employees ORDER BY employee_id LIMIT 10 OFFSET 10;

-- Page 3 (using shorthand syntax offset, count):
SELECT * FROM employees ORDER BY employee_id LIMIT 20, 10;
```
