# Day 02: Dealing with Missing Data (NULL)

In database design, you will frequently encounter cases where a data value is unknown, blank, or not applicable. SQL represents this missing information using a special marker called **`NULL`**.

---

## 1. What is NULL?

`NULL` is **not** a value. 
*   It is **not** equal to the number `0`.
*   It is **not** equal to an empty string `""` or spaces `" "`.
*   It is simply a marker representing **missing, unknown, or unassigned data**.

*Analogy:* Imagine a paper questionnaire.
*   If someone writes `0` for their income, their income is known to be **zero dollars**.
*   If someone leaves the income field **completely blank**, their income is **unknown** (`NULL`).

---

## 2. Filtering NULL Values: The Common Mistake

Because `NULL` represents an unknown, you cannot compare it using standard arithmetic operators like `=` or `!=`. 

In SQL, any direct comparison with `NULL` yields `UNKNOWN` (neither True nor False).

*   `5 = NULL` ➡️ `UNKNOWN`
*   `NULL = NULL` ➡️ `UNKNOWN`

### ❌ The Wrong Way:
```sql
-- This will return 0 rows! You cannot check equality with NULL using =
SELECT first_name, email FROM employees
WHERE email = NULL; 
```

### ✅ The Correct Way: `IS NULL` and `IS NOT NULL`
To check for missing data, SQL provides the special comparison phrases: `IS NULL` and `IS NOT NULL`.

#### Finding rows with missing data:
```sql
-- Find employees who do not have an email address stored
SELECT first_name, email FROM employees
WHERE email IS NULL;
```

#### Finding rows with defined data:
```sql
-- Find employees who DO have an email address stored
SELECT first_name, email FROM employees
WHERE email IS NOT NULL;
```

## 4. The NULL-Safe Equal Operator (`<=>`)

In standard SQL, comparing `NULL = NULL` yields `UNKNOWN` (0 rows returned). However, MySQL provides a special operator called **`<=>`** (NULL-Safe Equal Operator).

Unlike `=`, **`<=>`** treats `NULL` as a comparable value:
*   `SELECT 5 <=> 5;` ➡️ `1` (TRUE)
*   `SELECT 5 <=> NULL;` ➡️ `0` (FALSE)
*   `SELECT NULL <=> NULL;` ➡️ `1` **(TRUE!)**

```sql
-- Find rows where commission_pct matches a value, INCLUDING NULLs:
SELECT employee_id, first_name, commission_pct 
FROM employees
WHERE commission_pct <=> NULL;
```

---

## 5. The `ISNULL()` Function

In addition to the standard SQL predicate `WHERE column IS NULL`, MySQL provides a built-in `ISNULL(expression)` function.

```sql
-- Returns 1 if expression is NULL, otherwise 0:
SELECT ISNULL(email) FROM employees;

-- Filter using ISNULL():
SELECT first_name FROM employees WHERE ISNULL(commission_pct);
```

---

## 📊 Summary Comparison of NULL Operations

| Syntax | Description | Example Result |
| :--- | :--- | :--- |
| **`col = NULL`** | ❌ Incorrect equality test | Resolves to `UNKNOWN` (0 rows) |
| **`col IS NULL`** | ✅ Standard SQL check for missing data | `TRUE` if column is NULL |
| **`col IS NOT NULL`** | ✅ Standard SQL check for existing data | `TRUE` if column has a value |
| **`col1 <=> col2`** | 🔑 **NULL-Safe Equal**: `NULL <=> NULL` returns TRUE | `1` if both sides match (even if both are NULL) |
| **`ISNULL(col)`** | ⚙️ MySQL function wrapper for `IS NULL` | `1` if NULL, `0` if NOT NULL |
