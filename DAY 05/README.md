# DAY 05: Subqueries, Set Operators & CTEs

This directory contains the curriculum, practice exercises, and scripts for mastering subqueries, set operations, and Common Table Expressions (CTEs) in MySQL.

---

## 📚 Chapters & Content Outline

*   **[1. Subqueries - Single-row and Multi-row](1.%20Subqueries%20-%20Single-row%20and%20Multi-row.md)** - Master nested queries. Understand the execution flow of inner vs. outer queries and learn how to use Single-row comparison operators alongside Multi-row operators (`IN`, `ANY`, `ALL`).
*   **[2. Set Operators - UNION, INTERSECT, and EXCEPT](2.%20Set%20Operators%20-%20UNION%2c%20INTERSECT%2c%20and%20EXCEPT.md)** - Learn how to combine rows from multiple SELECT queries using set operations. Explore `UNION` vs. `UNION ALL`, and learn to emulate standard SQL `INTERSECT` and `EXCEPT` operations in MySQL.
*   **[3. Common Table Expressions - CTEs](3.%20Common%20Table%20Expressions%20-%20CTEs.md)** - Learn to define modular, highly readable virtual tables using the `WITH` clause. Explore the advantages of CTEs over standard subqueries and see a simple recursive CTE pattern.
*   **[4. Day 5 Hands-on Practice and Exercises](4.%20Day%205%20Hands-on%20Practice%20and%20Exercises.md)** - Test your skills against 13 subquery questions, nested subquery challenges, and Set Operator practice tasks.
*   **[day5_practice_script.sql](day5_practice_script.sql)** - Ready-to-run SQL file to practice Day 5 concepts directly on your database.
