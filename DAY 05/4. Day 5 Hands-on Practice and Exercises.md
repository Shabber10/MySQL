# Day 05: Chapter 4 — Hands-on Practice & Exercises

This guide contains practice exercises designed to test your understanding of Subqueries (Single-row and Multi-row), Set Operators, and CTEs.

---

## 📊 Database Schema Setup

To solve these exercises, we use the `Employees` table populated as follows:

### `Employees` Table
| emp_id | emp_name | salary | dept |
| :--- | :--- | :--- | :--- |
| 1 | John | 5000 | HR |
| 2 | Alice | 12000 | IT |
| 3 | Bob | 20000 | IT |
| 4 | David | 35000 | Finance |
| 5 | Emma | 25000 | Finance |
| 6 | Raj | 15000 | HR |

---

## 🟢 Part 1: Single-row Subquery Questions

### Q1. Find the employee who earns the maximum salary.
*   **Query**:
    ```sql
    SELECT emp_name, salary
    FROM Employees
    WHERE salary = (SELECT MAX(salary) FROM Employees);
    ```
*   **Expected Output**:
    | emp_name | salary |
    | :--- | :--- |
    | David | 35000 |

### Q2. Find the employee who earns the minimum salary.
*   **Query**:
    ```sql
    SELECT emp_name, salary
    FROM Employees
    WHERE salary = (SELECT MIN(salary) FROM Employees);
    ```
*   **Expected Output**:
    | emp_name | salary |
    | :--- | :--- |
    | John | 5000 |

### Q3. Find employees who earn more than Alice.
*   **Query**:
    ```sql
    SELECT emp_name, salary
    FROM Employees
    WHERE salary > (SELECT salary FROM Employees WHERE emp_name = 'Alice');
    ```
*   **Expected Output**:
    | emp_name | salary |
    | :--- | :--- |
    | Bob | 20000 |
    | David | 35000 |
    | Emma | 25000 |
    | Raj | 15000 |

### Q4. Find employees who work in the same department as David.
*   **Query**:
    ```sql
    SELECT emp_name, dept
    FROM Employees
    WHERE dept = (SELECT dept FROM Employees WHERE emp_name = 'David');
    ```
*   **Expected Output**:
    | emp_name | dept |
    | :--- | :--- |
    | David | Finance |
    | Emma | Finance |

### Q5. Find the employees who earn more than the average salary of all employees.
*   **Query**:
    ```sql
    SELECT emp_name, salary
    FROM Employees
    WHERE salary > (SELECT AVG(salary) FROM Employees);
    ```
*   **Expected Output**:
    | emp_name | salary |
    | :--- | :--- |
    | Bob | 20000 |
    | David | 35000 |
    | Emma | 25000 |

### Q6. Find employees who are in the same department as Raj but not Raj himself.
*   **Query**:
    ```sql
    SELECT emp_name, dept
    FROM Employees
    WHERE dept = (SELECT dept FROM Employees WHERE emp_name = 'Raj')
      AND emp_name <> 'Raj';
    ```
*   **Expected Output**:
    | emp_name | dept |
    | :--- | :--- |
    | John | HR |

## 🟡 Part 2: Multi-row Subquery Questions

### Q7. Find employees who work in the same department as Bob.
*   **Query**:
    ```sql
    SELECT emp_name, dept
    FROM Employees
    WHERE dept IN (SELECT dept FROM Employees WHERE emp_name = 'Bob');
    ```
*   **Expected Output**:
    | emp_name | dept |
    | :--- | :--- |
    | Alice | IT |
    | Bob | IT |

### Q8. Find employees whose salary equals any salary in the IT department.
*   **Query**:
    ```sql
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary IN (SELECT salary FROM Employees WHERE dept = 'IT');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | Alice | 12000 | IT |
    | Bob | 20000 | IT |

### Q9. Find employees who earn more than ANY employee in the HR department.
*   **Query**:
    ```sql
    -- Evaluates to greater than the minimum HR salary (5000)
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary > ANY (SELECT salary FROM Employees WHERE dept = 'HR');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | Alice | 12000 | IT |
    | Bob | 20000 | IT |
    | David | 35000 | Finance |
    | Emma | 25000 | Finance |
    | Raj | 15000 | HR |

### Q10. Find employees who earn more than ALL employees in the HR department.
*   **Query**:
    ```sql
    -- Evaluates to greater than the maximum HR salary (15000)
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary > ALL (SELECT salary FROM Employees WHERE dept = 'HR');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | Bob | 20000 | IT |
    | David | 35000 | Finance |
    | Emma | 25000 | Finance |

### Q11. Find employees whose salary is less than ANY salary in the Finance department.
*   **Query**:
    ```sql
    -- Evaluates to less than the maximum Finance salary (35000)
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary < ANY (SELECT salary FROM Employees WHERE dept = 'Finance');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | John | 5000 | HR |
    | Alice | 12000 | IT |
    | Bob | 20000 | IT |
    | Emma | 25000 | Finance |
    | Raj | 15000 | HR |

### Q12. Find employees whose salary is less than ALL salaries in the Finance department.
*   **Query**:
    ```sql
    -- Evaluates to less than the minimum Finance salary (25000)
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary < ALL (SELECT salary FROM Employees WHERE dept = 'Finance');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | John | 5000 | HR |
    | Alice | 12000 | IT |
    | Bob | 20000 | IT |
    | Raj | 15000 | HR |

### Q13. Find employees who work in departments where at least one employee earns more than 30000.
*   **Query**:
    ```sql
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE dept IN (SELECT DISTINCT dept FROM Employees WHERE salary > 30000);
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | David | 35000 | Finance |
    | Emma | 25000 | Finance |

## 🔴 Part 3: Intermediate & Nested Subqueries

### Q14. Find employees who earn more than the average salary of the IT department.
*   **Query**:
    ```sql
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary > (SELECT AVG(salary) FROM Employees WHERE dept = 'IT');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | Bob | 20000 | IT |
    | David | 35000 | Finance |
    | Emma | 25000 | Finance |
    | Raj | 15000 | HR |
    *(Note: Average salary of IT is 16000).*

### Q15. Find employees who earn more than the lowest paid employee in the Finance department.
*   **Query**:
    ```sql
    SELECT emp_name, salary, dept
    FROM Employees
    WHERE salary > (SELECT MIN(salary) FROM Employees WHERE dept = 'Finance');
    ```
*   **Expected Output**:
    | emp_name | salary | dept |
    | :--- | :--- | :--- |
    | David | 35000 | Finance |
    *(Note: Lowest Finance salary is 25000).*

### Q16. Find the employee with the second highest salary.
*   **Query**:
    ```sql
    SELECT emp_name, salary
    FROM Employees
    WHERE salary = (
        SELECT MAX(salary)
        FROM Employees
        WHERE salary < (SELECT MAX(salary) FROM Employees)
    );
    ```
*   **Expected Output**:
    | emp_name | salary |
    | :--- | :--- |
    | Emma | 25000 |

### Q17. Get all employees who work in the department that has the employee with the absolute minimum salary.
*   **Query**:
    ```sql
    SELECT emp_name, dept
    FROM Employees
    WHERE dept = (
        SELECT dept
        FROM Employees
        WHERE salary = (SELECT MIN(salary) FROM Employees)
    );
    ```
*   **Expected Output**:
    | emp_name | dept |
    | :--- | :--- |
    | John | HR |
    | Raj | HR |
