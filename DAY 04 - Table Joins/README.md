# DAY 04: Table Joins

This directory contains the curriculum, exercises, and practice scripts for **Table Joins**.

## 📚 Chapters & Content Outline
*   **[1. What is a Join and Types of Joins](1.%20What%20is%20a%20Join%20and%20Types%20of%20Joins.md)** - Get the foundational definitions of joins, understand the PK-FK relational mapping mechanism, and see an overview classification of all join types.
*   **[2. Inner, Equi, and Non-Equi Joins](2.%20Inner%2c%20Equi%2c%20and%20Non-Equi%20Joins.md)** - Learn the mechanics of standard INNER JOINs, the equality-based EQUI JOINs, and non-equality comparison JOINs (using `<`, `>`, `!=`, or `BETWEEN`).
*   **[3. Outer Joins - Left and Right Join](3.%20Outer%20Joins%20-%20Left%20and%20Right%20Join.md)** - Master handling missing data with LEFT and RIGHT joins, null padding, and the `IS NULL` search pattern for orphaned data.
*   **[4. Full Outer and Natural Joins](4.%20Full%20Outer%20and%20Natural%20Joins.md)** - Emulate FULL OUTER JOIN using UNION in MySQL, and understand implicit NATURAL JOIN columns.
*   **[5. Self and Cross Joins](5.%20Self%20and%20Cross%20Joins.md)** - Join a table to itself for hierarchies (Self Join) and create Cartesian products (Cross Join).
*   **[6. Join Optimization and Performance](6.%20Join%20Optimization%20and%20Performance.md)** - Deep dive into database internals: Nested Loops vs. Hash Joins (MySQL 8.0+), indexing join keys, and forcing orders with `STRAIGHT_JOIN`.
*   **[7. Hands-on Practice and Exercises](7.%20Hands-on%20Practice%20and%20Exercises.md)** - Test your learning with e-commerce exercises, including non-equi joins and multi-table joins.
*   **[day4_practice_script.sql](day4_practice_script.sql)** - Executable SQL file to practice all Join operations hands-on.
