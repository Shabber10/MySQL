# Day 10/11: Chapter 2 — Scheduled Tasks with Events

A **MySQL Event** is a background task that runs automatically according to a defined schedule. 

While **Triggers** fire in response to data modifications (`INSERT`/`UPDATE`/`DELETE`), **Events** fire in response to **time** (similar to a `cron` job on Linux or Windows Task Scheduler).

---

## ⚙️ Enabling the MySQL Event Scheduler

By default, the MySQL Event Scheduler thread may be disabled. You must enable it before events will execute.

### Checking Event Scheduler Status:
```sql
SHOW VARIABLES LIKE 'event_scheduler';
```

### Enabling the Event Scheduler:
```sql
-- Enable for the current running session/server instance:
SET GLOBAL event_scheduler = ON;

-- Or set value to 1:
SET GLOBAL event_scheduler = 1;
```

---

## 🛠️ Event Schedule Types

MySQL supports two types of event schedules:
1. **One-Time Events**: Executes once at a specific future timestamp.
2. **Recurring Events**: Executes repeatedly at specified regular intervals (`EVERY 1 DAY`, `EVERY 1 HOUR`, etc.) within an optional date window (`STARTS` ... `ENDS`).

---

## 💡 Practical Examples

### Example 1: One-Time Scheduled Event

Schedule a single database maintenance task to run 1 hour from now:

```sql
DELIMITER //

CREATE EVENT e_one_time_cleanup
ON SCHEDULE AT CURRENT_TIMESTAMP + INTERVAL 1 HOUR
DO
BEGIN
    DELETE FROM TemporaryTokens WHERE expires_at < NOW();
END //

DELIMITER ;
```

---

### Example 2: Recurring Scheduled Event (Daily Maintenance Cleanup)

Delete expired sessions and old temporary logs every day at midnight:

```sql
DELIMITER //

CREATE EVENT e_daily_log_cleanup
ON SCHEDULE EVERY 1 DAY
STARTS (CURRENT_DATE + INTERVAL 1 DAY) -- Starts tomorrow at 00:00:00
DO
BEGIN
    DELETE FROM AuditLog WHERE created_at < NOW() - INTERVAL 30 DAY;
END //

DELIMITER ;
```

---

### Example 3: Recurring Event with Summary Aggregation (Hourly Sales Snapshot)

Calculate hourly sales totals and insert a summary row into `HourlySalesSummary` every hour:

```sql
DELIMITER //

CREATE EVENT e_hourly_sales_summary
ON SCHEDULE EVERY 1 HOUR
DO
BEGIN
    INSERT INTO HourlySalesSummary (summary_hour, total_sales, total_orders)
    SELECT 
        DATE_FORMAT(NOW(), '%Y-%m-%d %H:00:00'),
        IFNULL(SUM(amount), 0),
        COUNT(*)
    FROM Orders
    WHERE order_date >= NOW() - INTERVAL 1 HOUR;
END //

DELIMITER ;
```

## 📝 Managing Scheduled Events

### A. Viewing Events in a Database
```sql
SHOW EVENTS FROM day11_practice;
```

### B. Disabling / Enabling an Event Temporary
```sql
-- Temporarily disable an event without deleting it:
ALTER EVENT e_daily_log_cleanup DISABLE;

-- Re-enable the event:
ALTER EVENT e_daily_log_cleanup ENABLE;
```

### C. Altering Event Schedules
```sql
ALTER EVENT e_daily_log_cleanup
ON SCHEDULE EVERY 12 HOUR;
```

### D. Dropping an Event
```sql
DROP EVENT IF EXISTS e_daily_log_cleanup;
```
