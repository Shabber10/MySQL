# Day 11: Chapter 2 — Scheduled Tasks with Events

A **MySQL Event** is a task that runs automatically on a predefined schedule, similar to Cron jobs in Linux or Task Scheduler in Windows. Events allow you to automate periodic database maintenance, such as clearing expired sessions, generating daily reports, or archiving old logs.

---

## ⚙️ 1. Enabling the Event Scheduler

Events are managed by the MySQL **Event Scheduler** thread. You must check and enable this thread before events can execute.

### Check Event Scheduler Status:
```sql
SHOW VARIABLES LIKE 'event_scheduler';
-- or
SELECT @@event_scheduler;
```

### Turn On Event Scheduler:
```sql
SET GLOBAL event_scheduler = ON;
```

---

## 🛠️ 2. Creating Events

MySQL supports two types of events:
1. **ONE-TIME Events:** Executes once at a specific timestamp (`ON SCHEDULE AT`).
2. **RECURRING Events:** Executes repeatedly at regular intervals (`ON SCHEDULE EVERY`).

### Syntax:
```sql
DELIMITER //

CREATE EVENT event_name
ON SCHEDULE EVERY interval_value INTERVAL_UNIT
STARTS start_timestamp
ENDS end_timestamp
DO
BEGIN
    -- SQL statements to execute
END //

DELIMITER ;
```

---

## 💻 3. Practical Examples

### Example 1: One-Time Scheduled Event
Delete temporary audit logs 1 hour from now.

```sql
CREATE EVENT cleanup_temp_logs
ON SCHEDULE AT CURRENT_TIMESTAMP + INTERVAL 1 HOUR
DO
    DELETE FROM SalaryAudit WHERE changed_by = 'test_user';
```

### Example 2: Recurring Daily Cleanup Event
Archive or purge expired login sessions every day at midnight.

```sql
DELIMITER //

CREATE EVENT daily_session_cleanup
ON SCHEDULE EVERY 1 DAY
STARTS '2026-08-07 00:00:00'
DO
BEGIN
    DELETE FROM user_sessions 
    WHERE last_active < NOW() - INTERVAL 7 DAY;
END //

DELIMITER ;
```

---

## 🗑️ 4. Managing Events

### View All Events:
```sql
SHOW EVENTS;
```

### Disable or Enable an Event:
```sql
ALTER EVENT daily_session_cleanup DISABLE;
ALTER EVENT daily_session_cleanup ENABLE;
```

### Drop an Event:
```sql
DROP EVENT IF EXISTS daily_session_cleanup;
```
