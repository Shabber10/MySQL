# Day 11: Hands-on Practice & Exercises

This module contains practical exercises to build, test, and verify Database Triggers and Scheduled Events in MySQL.

---

## 📋 Exercise Overview

1. **Exercise 1:** Create an `AFTER INSERT` trigger on `Orders` to automatically subtract stock from `Products`.
2. **Exercise 2:** Create an `AFTER INSERT` trigger to log order details into an `AuditLog` table.
3. **Exercise 3:** Create a `BEFORE INSERT` trigger with `SIGNAL SQLSTATE` to reject orders if product stock is insufficient.
4. **Exercise 4:** Enable the `event_scheduler` global thread.
5. **Exercise 5:** Create a recurring `EVENT` that runs every 1 minute to summarize total sales into `DailySalesSummary`.

---

## 🛠️ Solutions & Execution Guide

Refer to `day11_practice_script.sql` in this folder for the full executable script.

```sql
-- Test Exercise 1 & 2: Insert order and verify stock reduction + audit log
INSERT INTO Orders (customer_name, product_id, quantity, amount)

-- Check Products stock (reduced by 2):
SELECT * FROM Products WHERE product_id = 101;

-- Check AuditLog entry:

-- Test Exercise 3: Insert order exceeding available stock (should FAIL with custom error):
```
