# Day 12: Chapter 1 — Database Security and User Accounts

In MySQL, security starts at the connection level. The database system restricts access by defining user accounts and verifying their credentials before granting entry.

---

## 👤 1. Understanding MySQL User Accounts

A MySQL user account is uniquely identified by two parts:
1.  **Username** (e.g., `admin`, `faculty`)
2.  **Host** from which the user can connect (e.g., `localhost` for local connection, `192.168.1.50` for a specific IP, or `%` to allow connections from any machine).

The syntax for identifying a user account is:
```sql
'username'@'hostname'
```
*   `'admin'@'localhost'` $\rightarrow$ User `admin` can only connect from the local database server.
*   `'admin'@'%'` $\rightarrow$ User `admin` can connect from any network location.

---

## 🛠️ 2. Creating User Accounts

To create a new user account, use the `CREATE USER` statement.

### Syntax:
```sql
CREATE USER 'username'@'hostname' IDENTIFIED BY 'password';
```

### Examples:
```sql
-- Create an administrator account
CREATE USER 'admin'@'localhost' IDENTIFIED BY 'admin123';

-- Create a faculty account
CREATE USER 'faculty'@'localhost' IDENTIFIED BY 'faculty123';
```

---

## 📋 3. Listing (Displaying) All Users in MySQL

In MySQL, all user accounts and their details are stored in the system table `mysql.user`.

To list all user accounts:
```sql
SELECT User, Host FROM mysql.user;
```

### Example Output:
```text
+------------------+-----------+
| User             | Host      |
+------------------+-----------+
| root             | localhost |
| admin            | localhost |
| faculty          | localhost |
| mysql.infoschema | localhost |
| mysql.session    | localhost |
| mysql.sys        | localhost |
+------------------+-----------+
```
> [!NOTE]
> To query the `mysql.user` table, you must be logged in as a privileged user (like `root`).

---

## ❌ 4. Dropping (Deleting) User Accounts

If a user account is no longer needed, you can delete it using the `DROP USER` statement.

### Dropping a Single User:
```sql
DROP USER 'faculty'@'localhost';
```

### Dropping Multiple Users at Once:
```sql
DROP USER 'faculty'@'localhost', 'admin'@'localhost';
```

---

## ⚠️ 5. Safe Practices: Deleting Users

Unlike tables where you can delete all records, there is **no single command** like `DROP ALL USERS` in MySQL. This is a safety measure to prevent administrators from accidentally locking themselves out of the system.

### How to Safely Clean Up Users:
1.  List all current users:
    ```sql
    SELECT User, Host FROM mysql.user;
    ```
2.  Identify the specific custom accounts you created (e.g., `admin`, `faculty`, `test_user`).
3.  Drop them explicitly by naming them:
    ```sql
    DROP USER 'admin'@'localhost', 'faculty'@'localhost';
    ```
4.  **CRITICAL:** Never drop the system users (e.g., `root`, `mysql.sys`, `mysql.session`) as doing so will break the MySQL server installation.
